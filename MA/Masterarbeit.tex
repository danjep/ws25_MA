\section{Introduction}\label{sec:intro}
Almost every computer that is in use today provides multiple simultaneously running processors to satisfy the surging demand for computational power. In order to reap the benefits that multiple processors provide, developers have to design their programs to use concurrently running threads. 
Multiple threads may operate on the same memory and could interfere with the others' stored values. In \Cref{fig:example} two threads each write a value on a memory location that the other one reads. 
Multiple different executions are possible: If thread $T_1$ is executed completely before $T_2$ the result is different to when $T_2$ is executed completely before $T_1$. The reason is that the threads can be interleaved in different ways. The situation where two or more threads access the same memory address and at least one of them uses a write operation is called a \textit{data race} and is one reason for the possibility of different executions. Another reason is that the operations of each thread may be reordered for performance reasons and hence, the execution is not consistent with the order of the program anymore. \\

Every program that a thread might execute consists of instructions which in turn consist of memory accesses. The instruction \texttt{a=y} for example consists of two operations, reading the value of \texttt{y} and writing the read value to \texttt{a}. These two operations are usually called events.
CPU architectures and compilers may reorder the events in such programs for performance reasons and interleave the two threads as they see fit. 
Since this permits different executions for the same program, programmers need to be careful about their code. Programming languages and CPU architectures provide \textit{memory consistency models} (MCMs) which give the code a semantic and let the programmers know how their code will be handled by the compiler and hardware. \\
The most intuitive and restrictive MCM is Lamport's \textit{Sequential Consistency} (SC) \cite{Lam79} which guarantees that operations are executed as if they were in some sequential order and the operations of each thread follow the order in which they are written.\\
For the example in \Cref{fig:example} this means that either one of the threads is executed completely before the other or that both writes are done before the reads. Only the result of $a=b=0$ is not permitted, since this is not consistent with the order of each thread. 
This shows, that MCMs give developers certain guarantees for how the program will be compiled and executed. \\ 
The memory consistency model of a CPU architecture describes how the hardware will behave if it runs the instructions of the compiled program. For the program to have the intended semantics, the code needs to respect the rules of the language MCM and the compiler has to comply with both the language MCM and the hardware MCM.
Essentially, the MCMs  determine which update to the shared memory is seen by which thread at what time.

As can be seen in the example, the memory consistency model can restrict the possible outcomes of a program. But the presence of a MCM may not guarantee the behavior that it's developers intended. 
MCMs are defined by humans and can have bugs. They may not capture the behavior of the architecture correctly or be insufficiently defined. 
Consequently there is research on how MCMs can be verified and how the verification can be done effectively. \\
The succeeding pages are dedicated to explaining the concepts of MCMs and the CAT language, before we explain what the contribution of this master's thesis will be.


\subsection{Memory Consistency Models}\label{sec:MCM}
Memory Consistency Models constitute what programmers and execution environments agree on when it comes to how concurrent programs are allowed to be executed. They define consistency constraints on execution graphs and provide guarantees for how memory accesses are processed on shared memory.
Memory models can roughly be divided into two classes, operational models and axiomatic ones.
Operational models are abstractions of real machines with idealized components and may be perceived as being more intuitive. 
Axiomatic models constrain relations on memory operations to allow or disallow behavior of programs. To this end one can understand memory operations as nodes in a graph where the edges are relations between these operations like the \textit{program order} (\po) or \textit{read-from} (\rf).
While \po{} describes the order of instructions within a single thread, \rf{} depicts for each read which write provides the value that is extracted. \\
Therefore the \po{} relation is given by how the program is written and \rf{} depends on the execution.
From this, one can deduce that there are multiple possible execution graphs. In \Cref{fig:examplegraph,fig:storebuffering} one can see the possible execution graphs of the example from \Cref{fig:example}.

Since simulation \cite{Mad+10} and verification \cite{Alg+13} are substantially faster on axiomatic models, research has focused on this type. 
Axiomatic models are defined in three stages: Map each instruction onto a mathematical object and defining relations on the events. Then, enumerate all candidate executions like in \Cref{fig:examplegraph,fig:storebuffering}. Finally, decide which executions are valid according to the constraints on the relations. \\
To validate that a program is executed according to a given MCM is called \textit{consistency checking} and can be reduced to a certain depth-first search on the execution graph \cite{Kok+23}. A program is consistent with a model if it fulfills all constraints of the model. \\
For consistency checking there exist many automated tools like HERD \cite{Alg+14}, GenMC \cite{KokVaf21} and Dartagnan \cite{Pon+18}. 
The issue this master's thesis deals with is verification of memory consistency models which is a very different problem. According to Grünke et al. \cite{Gru+26} it consists of five tasks that an automated verification tool should ideally cover:
The first task is to check generic properties of MCMs like permitting no out-of-thin-air values. The second task is to review properties referring to operation's semantics like \textit{barrier monotonicity} (there are fewer possible executions when inserting synchronizations). The next task is to compare models and determine which is stronger. Task four is to create litmus tests that check whether a language or architecture implements a model. The last task is to verify compiler transformations. \\
Since we want to verify the models and not a program, it is important to check properties for every program that could be executed under the model.
For this task there exist two automated tools, KATER \cite{Kok+23} and RAT \cite{Gru+26} which both are not able to handle every possible MCM but only a fragment.

Besides Lamport's Sequential Consistency, there are models that are less restrictive like \textit{SC per Location} (also known as \textit{Coherence} or \textit{UNIPROC}) and \textit{Total Store Order} (TSO)\cite{SPA92} which were developed to allow for more optimization. Besides these rather theoretical models, there exists MCMs that describe the behavior of hardware like Power \cite{Mad+12}, of a programming language like Java Memory Model \cite{Man+05} or of an operating system like Linux Kernel Memory Model (LKMM) \cite{Alg+18,LKM25} and many more types for various applications.


\subsection{The CAT language} \label{sec:cat}

In 2014 Alglave et al. proposed an axiomatic framework for modelling weak memory and the corresponding language CAT \cite{Alg+14} which has since then become the standard for writing axiomatic memory consistency models. In this case, weakness is defined as accepting a larger number of possible executions of a program than stronger models. 
The CAT language uses base sets which are the events of an execution. There are the set of all events $E$, the initial writes $IW$, all reads $R$, writes $W$ and fences $F$, the branch events $B$ and the memory events $M$ which are the reads and writes \cite{Alg+16}.
CAT has some built-in base relations which include the already mentioned \po{} and \rf. Besides those, there are the \textit{same location} relation \loc, which connects all events of one particular memory location, the \textit{external} relation \ext{} which includes all pairs of events that originate from different threads, the \textit{coherence order} \co{} which is a total order of writes on the same memory location, the \textit{read-modify-write} relation \rmw{} that relates a read event with a write event of the same memory location that can be interpreted as an atomic operation and the \textit{identity} and empty relations \texttt{id} and $0$. Furthermore it provides the constraints \texttt{acyclic}, \texttt{irreflexive} and \texttt{empty} which are sufficient for expressing every desired model and property. 

\begin{figure}[H]
\begin{align*}
\langle cat\rangle &:= \bangle{constraint}~ \bangle{rel} \mid \langle cat \rangle~ \langle cat\rangle \\
\bangle{constraint} &:= \texttt{acyclic} \mid \texttt{irreflexive} \mid \texttt{empty} \\
\bangle{rel} &:= \bangle{base\_rel} \mid \langle rel \rangle . \bangle{rel} \mid \bangle{rel}^* \mid \bangle{rel} \cup \bangle{rel} \mid \bangle{rel} \cap \bangle{rel} \\ &\quad \mid \bangle{rel}^{-1} \mid \bangle{rel}^+ \mid \bangle{rel}? \mid \bangle{base\_set} \times \bangle{base\_set} \mid \textcolor{teal}{\bangle{rel}\setminus \bangle{rel} \mid{} \sim\bangle{rel}} \\
\bangle{base\_rel} &:= \textsf{po} \mid \text{\rf} \mid \textsf{rmw} \mid \co \mid \loc \mid \ext \mid \textsf{id} \mid \textsf{0} \\
\bangle{base\_set} &:= \text{R} \mid \text{W} \mid \text{F} \mid \text{B} \mid \text{M} \mid \text{IW} \mid \text{E}
\end{align*}
\caption{The CAT language according to \cite{Alg+16}, where $\bangle{rel}^+$ is the transitive closure, $\bangle{rel}?$ the reflexive closure, $\bangle{rel}^*$ the reflexive and transitive closure, $\sim\bangle{rel}$ the complement. Furthermore, $\textsf{0}$ denotes the empty relation and \id~ the identity relation. The $^*$ operator is also called Kleene-star. \\
The \textcolor{teal}{teal}-colored part is what differentiates CAT from rational CAT.}   
\label{fig:cat}
\end{figure}

Besides the given base relations, one can define derived relations in the CAT language like \textit{from-read} (\fr), connecting reads to those writes that occur after the write operation from which they read or \textit{happens-before} (\hb) which relates each event to the ones that occurred before \cite{Lam78}. The derivations can be written with the keyword \texttt{let} and using the operations in \Cref{fig:cat} like this:
\[\texttt{let } \fr = \text{\rf}^{-1}\text{.\co} \qquad \texttt{let } \text{\hb}=\textsf{po}\cup \text{\co}\cup \text{\rf} \cup \text{\fr}\]
The language also includes some base sets of events. These include the set of all events E, all reads (R) and writes (W), initial writes IW and fences F. \\
The Memory Models from the last section can be formalized according to \cite{Gru+26,Kou+24} like this:
\begin{align*}
&\text{(SC) } \hfill &\texttt{acyclic }\hb \\
&\text{(TSO) } \hfill &\texttt{irreflexive }(\textsf{ppo} \cup (\rf \cap \ext) \cup \co \cup \fr)^+ \\
&\text{(SC per Location)} \hfill &\texttt{acyclic } (\po \cap \loc) \cup (\rf \cup \co \cup \fr)
\end{align*}

\subsection{Contribution}
This master's thesis will present a new proof-system for comparing memory consistency models that directly handles relations and uses invariants to handle potentially infinite decompositions of Kleene-star terms.
At the center of this proof system is a set of rules that transform relational inclusion terms like $\Relr \subseteq \Rels$ and produce the implication $\true \impl \relr \subseteq \rels$ which makes the inclusion a logical tautology.
By adding relation-specific rules, assumptions and definitions of derived relations (in the literature usually hypotheses) and handling the constraints to the relations that CAT expression use, we expand the results to memory consistency models defined in the CAT language.
\Cref{sec:kontext} will show what current lines of research exist in the field of weak memory and especially the work that has been done in verification of MCMs, before \Cref{sec:preliminaries} gives some preliminaries for a better understanding of this text and \Cref{sec:proofsys} shows the proof system that is at the center of this thesis. In \Cref{sec:constraints} we will see how any inclusion between CAT expressions for MCMs can be transformed into a relational inclusion. Following in \Cref{sec:implications,sec:transformations} are the rules that can proof any relational inclusion term that is confined to the syntax of rational CAT. The transformations and axioms in \Cref{sec:relationspecific,sec:assumptions} expand the capabilities of the proof system to include knowledge about the base relations and base sets of CAT.  \\
In \Cref{sec:soundness} we show the soundness of the proof system by proving each rule to be a valid implication or equality. \\
The Completeness in \Cref{sec:completeness} is shown via a translation of a cyclic proof system \cite{Gru+26} into ours. This includes translating every rule that is needed into a rule or a sequence of rules in our system and transforming the infinite cyclic proofs into finite ones using invariants. 

\section{Related Work}\label{sec:kontext}
There are currently several established lines of research in the field of weak memory. One obvious issue is the \textit{consistency checking} of programs under a given memory model \cite{Tun+23,KokVaf21}. Several automated tools that were developed in the last decade already handle this issue well. Examples are GenMC \cite{KokVaf21}, DARTAGNAN \cite{Pon+18} and HERD \cite{Alg+14}.
Furthermore, there is research on refining stateless model checking \cite{Jon+25}.
%In the realm of verification this would be on the program verification level. 
Some research groups instead examine the models themselves and their attributes \cite{LahBok22} and others the already mentioned operational models \cite{Ior+23,Doh+22}. Additionally, researchers are looking at ways of comparing \cite{Wic+17,Sha+23} and verifying \cite{Kok+23,And+25,Kir+20} memory consistency models which are closely related problems.

The first tool to verify MCMs was KATER \cite{Kok+23} which covered only a fragment of CAT that could be transformed into Kleene Algebra with Tests (KAT). This fragment excluded set difference, complement, intersections, converses and the construction of relations from sets. \\
Since a lot of MCMs like SC, TSO, Power and Arm8 could be defined without the use of these operations, KATER was already very useful and through the exclusion of complement and intersections the verification becomes PSPACE-complete instead of EXPSPACE-complete with intersection \cite{KozSmi97,Nak17} or undecidable with complement \cite{TarGiv87}.
Notably, the fragment of \cite{Kok+23} excludes the definitions of C11 and the Linux Kernel Memory Model (LKMM) \cite{Kou+24}. To include these models and others, intersections are needed.
The next year Koutsouridis et al. presented KATI \cite{Kou+24} which is able to handle converses and some intersections but was not implemented.

The first tool that addressed all intersections as well as inverses and construction of relations from sets (called rational CAT, see \Cref{fig:cat}) was RAT (Relational Algebra with Tableaus) which was developed by the supervisors of this master's thesis in 2025 \cite{Gru+26}. Their tool is able to handle the first four tasks of the verification with only the compiler transformations being left as an open issue. In their yet to be published work, they present a logical theory of relations where the unsatisfiability of a formula is equivalent to the model fulfilling a set of assertions.
By transforming the question of $\llbracket M\rrbracket \subseteq \semsof{M_{prop}}$ into $\semsof{M} \cap \overline{\semsof{M_{prop}}} = \emptyset$ and then a formula $ \phi_M \land \neg \phi_{M_{prop}}$ it proves whether the given model is stronger than the condition that is to be tested.
The formula is then decomposed until there exists a satisfying model for the formula or it is deemed unsatisfiable. 

Today there are many open questions in this field of research. Is it possible to automatically verify  more than the rational CAT fragment?
Can the popular models written in CAT be transformed into ones that are written in rational CAT?
Is it possible to verify compiler transformations?

\section{Preliminaries} \label{sec:preliminaries}

\subsection{Executions}
Executions consist of a set of all events $E$, the set of initial writes $IW$ and the base relations that are determined through the program and how it is executed. It is one possible instance of the relations on the memory events and describes the order in which the events occur. The fact that executions consist of elements with relations between them, allows us to interpret them as execution graphs like the ones in \Cref{fig:examplegraph,fig:storebuffering}.
\begin{definition}[Execution]
An execution $X$ is the following tuple:
\[X := (E, IW, \po, \rf, \rmw, \co, \loc, \ext)\]  
where $\po, \rf, \rmw, \co, \loc, \ext \subseteq E \times E$.
$\mathbb{E}$ denotes the set of all possible executions. 
%Furthermore, for any in CAT constructed relation $\bangle{rel}$, $\bangle{rel}_X$ denotes the instance of it on the execution $X$.
\end{definition}


\subsection{Semantics} \label{sec:semantics}
The semantics of a MCM $M$ can be defined along the definition of the CAT language. In general, they are the set of executions that the model allows. The semantics of relations is simply the set of elements in the relation.
\begin{definition}[Semantics of CAT Expressions] \label{def:catsem}
Let $M$ be a memory consistency model, $\bangle{cat}_1,\bangle{cat}_2$ be CAT expressions and\\ $\bangle{rel} \subseteq (E \times E)$ be a relation. The semantics of the CAT expressions are sets of executions and defined as follows:
\begin{align*}
\semsof{\bangle{cat}_1~ \bangle{cat}_2} & := \semsof{\bangle{cat}_1} \cap \semsof{\bangle{cat}_2} \\
\semsof{\texttt{empty}~ \bangle{rel}} &:= \{X \in \E \mid \nexists (e_1,e_2) \in \semsof{\bangle{rel}}\} \\
\semsof{\texttt{irreflexive}~ \bangle{rel}} &:= \{X \in \E \mid \forall e \in E: (e,e) \notin \semsof{\bangle{rel}} \} \\
\semsof{\texttt{acyclic}~ \bangle{rel}} &:= \semsof{\texttt{irreflexive}~ \bangle{rel}^+}
\end{align*} 
\end{definition}
For the relational subterms of the CAT expressions, the semantics differ in the regard that they are sets of edges in the execution graphs.
\begin{definition}[Semantics of Relational Expressions] \label{def:sem}
Let $\rel, \rel_1, \rel_2 \subseteq (E \times E)$ be relations. $\bangle{base\_rel}$ and $\bangle{base\_set}$ are as defined in \Cref{fig:cat}.
\begin{align*}
\semsof{\bangle{rel}_1 \subseteq \bangle{rel}_2} &:= \forall (e,e'):(e,e') \in \bangle{rel}_1 \impl (e,e') \in \bangle{rel}_2 \\
\semsof{\bangle{rel}_1.\bangle{rel}_2} &:= \{(e_1,e_2) \mid \exists e' \in E: (e_1,e') \in \semsof{\bangle{rel}_1} \land (e',e_2) \in \semsof{\bangle{rel}_2}\} \\
\semsof{\bangle{rel}_1 \cup \bangle{rel}_2} &:= \{\edge \mid \edgein \semsof{\bangle{rel}_1} \lor \edgein \semsof{\bangle{rel}_2} \} \\
\semsof{\bangle{rel}_1 \cap \bangle{rel}_2} &:= \{\edge \mid \edgein \semsof{\bangle{rel}_1} \land  \edgein \semsof{\bangle{rel}_2}\} \\
\semsof{\bangle{rel}_1 \setminus \bangle{rel}_2} &:= \{\edge \mid (e,e') \in \semsof{\bangle{rel}_1} \land (e,e') \notin \semsof{\bangle{rel}_2}\} \\
\semsof{\sim \bangle{rel}} &:= \{(e_1,e_2) \mid (e_1,e_2) \notin \semsof{\bangle{rel}}\} \\
\semsof{\bangle{rel}^{-1}} &:= \{(e_1,e_2) \mid (e_2,e_1) \in \semsof{\bangle{rel}}\} \\
\semsof{\bangle{rel}^+} &:= \{(e,e') \mid \exists e_1,\dots e_n \in E: e = e_1 \land e'=e_n \land \forall i\in [1,n-1]:\\
& (e_i,e_{i+1}) \in \semsof{\bangle{rel}}\} \\
\semsof{\bangle{rel}?} &:= \semsof{\bangle{rel}} \cup \id \\
\semsof{\bangle{rel}^*} &:= \semsof{\bangle{rel}^+} \cup \id \\
\semsof{\bangle{base\_set}_1 \times \bangle{base\_set}_2} &:= \{(e,e') \mid e \in \bangle{base\_set}_1, e' \in \bangle{base\_set}_2\} \\
\semsof{\bangle{base\_rel}} &:= \{ (e,e') \in \bangle{base\_rel} \}
\end{align*}
\end{definition}
To give a clear understanding of what the base relations are, we give definitions that are derived from those in Alglave et al. \cite{Alg+16,Alg+14}.
\begin{definition}[Semantics of Base Relations]
Let $E$ be the set of all events, $R$ the set of all read operations and $W$ the set of all write operations.
\begin{align*}
\semsof{\0} := \quad & \emptyset \times \emptyset \\
\semsof{\id} := \quad & \{(e,e) \mid e \in E\} \\
\semsof{\po} := \quad & \{\edgein E\times E \mid e \text{ and } e' \text{ belong to the same thread and }\\
& e \text{ occurs syntactically before } e' \text{ in the program}\} \\
\semsof{\loc} := \quad & \{\edgein E\times E \mid e \text{ and } e' \text{ are on the same memory location}\} \\
\semsof{\ext} := \quad & \{\edgein E\times E \mid e \text{ and } e' \text{ belong to different threads}\} \\
\semsof{\rf} := \quad & \{\edgein W \times R \mid e \text{ is the write that stores the value which } e' \text{ reads} \} \\
\semsof{\co} := \quad & \{\edgein W\times W \mid e' \text{ is a write on the same memory location} \\ & \text{ that is executed later than } e\} \\
\semsof{\rmw} := \quad & \{\edgein R \times W \mid e' \text{ is the next event after the read } e \text{ in the program order } \po\}
\end{align*}
\end{definition}
For better readability, the \semsof{\cdot} symbols can be omitted when dealing with relations, since the semantics are equal to the intuitive definition of relations.


\subsection{Notation}\label{sec:notation}
\paragraph{Abbreviation for Concatenation}
Let $\relr \subseteq (E \times E)$ be a relation. For any term where \relr~ is concatenated with itself $n \in \N$ times, we can instead write $\relr^n$. In this notation, $\relr$ is equal to $\relr^1$. This notation will shorten terms and increases readability. Furthermore, it yields a definition of the semantics of $\rel^+$ that is equivalent to the one in \Cref{def:sem}:
\begin{definition}[Alternative Definition of the Transitive Closure] \label{def:alttc}
Let $\rel \subseteq (E\times E)$ be a relation.
\[\semsof{\bangle{rel}^+} := \{(e,e') \mid \exists n \in \N: \edgein \bangle{rel}^n\}\] \end{definition}

\paragraph{Set Restrictions on Relations} 
Let $A \subseteq E$ be a set of events. $[A]$ denotes the relation $(A \times A) \cap \id$. This relation can be used to restrict other relations to certain sets of operations like writes and reads.
An example is $\relW.\po .\relR$, which restricts \po{} to only those elements which feature a write as the first event and a read as the second one. One can use this notation for assumptions about the relations in the CAT language. For example, the \rf{} relation can always be assumed to be restricted to writes in the first position and reads in the second one, i.e. $\relW.\rf .\relR$, since it relates writes to those reads which use the written data. \\
This notation is furthermore justified by the semantics of the CAT language, since the expression
\[\relW.\rf .\relR := \{(w,r) \mid (w,w) \in \relW \land (w,r) \in \rf \land (r,r) \in \relR\}\]
allows only for entries that consist of a write and a read event. 
In \Cref{sec:relationspecific} we use this notation to represent the known restrictions on the base relations in the rules and in \Cref{sec:assumptions} to integrate assumptions that are defined in the CAT file.

\section{The Proof System} \label{sec:proofsys}
In order to prove $\semsof{M} \subseteq \semsof{M_{prop}}$ we devise a general method of proving one model to be stronger than another based on inclusion between the relations. For this purpose, we design rules that derive the expression $M \subseteq M'$ from the statement $\true$. The derivation therefore acts according to logical implication, since $\true \impl M \subseteq M'$ would mean that the implied part holds. If there is no valid derivation from $\true$ to the inclusion that should be proven, then the inclusion cannot hold.
Since there may be multiple branches of reasoning it is important to clarify that every branch needs to end at \true{} in order to verify the inclusion. We call a branch that ends in \true{} \textit{closed} and one that does not \textit{open}. Correspondingly, we call a derivation tree \textit{closed} if every branch is closed and \textit{open} otherwise.

\begin{definition}[CAT Inclusion Proofs]
Let $M,M'$ be CAT expressions constituting sets of executions on a domain of events $E$. A CAT Inclusion Proof $\prf^{CAT}$ is a closed derivation tree that starts at the bottom with $M \subseteq M'$ and ends at potentially several axioms using the rules from this section.
Hence, the proof derives the implication $\true \impl M \subseteq M'$.
\end{definition}

These proofs need rules to handle the CAT constraints which are given in the next subsection (\Cref{sec:constraints}). 

When the constraints are eliminated, all that is left is a relational inclusion term.  We can then apply transformations (\Cref{sec:transformations}) and relational implications (\Cref{sec:implications}) on the relational terms. By transformations we mean rules that are based on equivalences like the commutativity of union and intersection. With the rules of the mentioned two subsections we can construct a \textit{Relational Inclusion Proof} $\prf$ for this inclusion term which is part of the CAT Inclusion Proof $\prf^{CAT}$.

\begin{definition}[Relational Inclusion Proofs]
Let $\relr,\rels \subseteq (E \times E)$ be two relations on a domain $E$. A Relational Inclusion Proof $\prf$ for the inclusion $\relr \subseteq \rels$ is a closed derivation tree that starts with the inclusion at the root and ends at potentially several leafs with \true{} using the rules in \Cref{sec:implications,sec:transformations}. The proof derives the implication $\true \impl \relr \subseteq \rels$. 
\end{definition}
This is the core element of the proof system. Putting the memory consistency models aside, this part of the rules allows us to prove any inclusion of relations that is universally true, like for example $a^* \subseteq (aa)^* \cup a(aa)^*$. 
Since the proof system we design, will handle CAT expressions and not just arbitrary relations, there are rules to capture the properties of the CAT base relations given in \Cref{sec:relationspecific}. Furthermore, there is a need to incorporate assumptions about the base relations and definitions of derived relations into the rules. We show this in \Cref{sec:assumptions}.


\subsection{Eliminating the Constraints}\label{sec:constraints}
One important aspect that one has to keep in mind when comparing models is that the constraints \texttt{acyclic}, \texttt{irreflexive} and \texttt{empty} inverse the inclusion of relations.
This means the following:
\begin{lemma}\label{lem:elimination}
Let $\relr_1, \relr_2 \subseteq (E \times E)$ be two relational terms. For any inclusion $\relr_1 \subseteq \relr_2$ it holds that $\bangle{constraint}~ \relr_2 \subseteq \bangle{constraint}~ \relr_1$ if the constraint is the same for each relation.
\end{lemma}
\begin{proof}
We can prove this for each of the constraints. 
Let the constraint be \texttt{empty}:
\begin{eqnarray*}
\sf r_1 \subseteq r_2 
& \impl &\forall X \in \E : (\nexists (e_1,e_2) \in {\sf r_2} \impl (e_1,e_2) \notin {\sf r_1}) \\
& \impl &(X \in \semsof{\texttt{empty}~ \relr_2} \impl X \in \semsof{\texttt{empty}~ \sf r_1}) \reason{\defof \semsof{\texttt{empty}}}\\
& \impl & \semsof{\texttt{empty}~ \sf r_2} \subseteq \semsof{\texttt{empty}~ \sf r_1}
\end{eqnarray*}

\noindent For the constraint \texttt{irreflexive}:
\begin{eqnarray*}
\sf r_1 \subseteq r_2 
& \impl &\forall X \in \E : (\forall e \in E: \nexists(e,e) \in {\sf r_2} \impl \forall e \in E_X: \nexists (e,e) \in {\sf r_1}) \\
& \impl &(X \in \semsof{\texttt{irreflexive}~ \relr_2} \impl X \in \semsof{\texttt{irreflexive}~ \sf r_1}) \reason{\defof \semsof{\texttt{irreflexive}}} \\
& \impl & \semsof{\texttt{irreflexive}~ \sf r_2} \subseteq \semsof{\texttt{irreflexive}~ \sf r_1}
\end{eqnarray*}

\noindent For the \texttt{acyclicity} constraint:
\begin{eqnarray*}
\sf r_1 \subseteq r_2 
& \impl &\forall X \in \E : (\forall e \in E: \nexists(e,e) \in {\sf r_2}^+ \impl \forall e \in E_X: \nexists (e,e) \in {\sf r_1}^+) \\
& \impl &(X \in \semsof{\texttt{acyclic}~ \relr_2} \impl X \in \semsof{\texttt{acyclic}~ \sf r_1}) \reason{\defof \semsof{\texttt{acyclic}}} \\
& \impl & \semsof{\texttt{acyclic}~ \sf r_2} \subseteq \semsof{\texttt{acyclic}~ \sf r_1}
\end{eqnarray*}
\end{proof}
\noindent From \Cref{lem:elimination} we can generate the following three rules:
\begin{rules}{Restraint Elimination} 
\inferrule*[left=(empty)] {\sf r_1 \subseteq r_2}{\sf \texttt{empty}~ r_2 \subseteq \sf \texttt{empty}~ r_1} \and 
\inferrule*[left=(acyclic)] {\sf r_1 \subseteq r_2}{\sf \texttt{acyclic}~ r_2 \subseteq \texttt{acyclic}~ r_1} \and
\inferrule*[left={(irreflexive)}] {\sf r_1 \subseteq r_2}{\sf \texttt{irreflexive}~ r_2 \subseteq \texttt{irreflexive}~ r_1}
\end{rules}

Since not every inclusion offers the comfort of having both models use the same constraint, they need to be converted. For this purpose there are some rules:

\begin{lemma}\label{lem:irracy}
For any relational term $\relr$, it holds that $\semsof{\mathtt{irreflexive}~ \relr^+} = \semsof{\mathtt{acyclic}~ \relr}$.
\end{lemma}
\begin{proof}
This is given via the semantics of $\semsof{\mathtt{acyclic}~ \bangle{rel}}$ in \Cref{def:catsem}.
\end{proof}

\begin{lemma}\label{lem:emptyirr}
For any relational term $\relr$ it holds that $\semsof{\mathtt{empty}~ \sf r} = \semsof{\mathtt{irreflexive}~ \sf r.r^{-1}}$.
\end{lemma}
\begin{proof} This can equally be proven using \Cref{def:catsem}.
\begin{eqnarray*}
\semsof{\texttt{empty}~ \sf r} &=& \{X \in \E \mid \nexists (e_1,e_2) \in \sf r\} \reason{\defof \semsof{\texttt{empty}}} \\
&=& \{X \in \E \mid \forall e,e' \in E: \nexists (e,e') \in \sf r\} \\
&= & \{X \in \E \mid \forall e \in E: \nexists (e,e) \in \sf r.r^{-1} \} \\
&=& \semsof{\texttt{irreflexive}~ \sf r.r^{-1}} \reason{\defof \semsof{\texttt{irreflexive}}}
\end{eqnarray*}
\end{proof}

\begin{lemma}\label{lem:irrempty}
For any relational term \relr{} it holds that $\semsof{\mathtt{irreflexive}~ \sf r} = \semsof{\mathtt{empty}~ \relr \cap \id}$.
\end{lemma}
\begin{proof}
\begin{eqnarray*}
\semsof{\texttt{irreflexive } \relr} &=& \{X \in \E \mid \forall e \in E: (e,e) \notin \relr\} \reason{\defof \semsof{\texttt{irreflexive}}} \\
&=& \{X \in \E \mid \forall e \in E: (e,e) \notin \relr \cap \id\} \\
&=& \{X \in \E \mid \nexists (e,e') \in \relr \cap \id\} \\
&=& \semsof{\texttt{empty } \relr \cap \id} \reason{\defof \semsof{\texttt{empty}}}
\end{eqnarray*}
\end{proof}

\begin{lemma}\label{lem:emptyacy}
For any relational term $\relr$ it holds that $\semsof{\mathtt{empty}~ \sf r} = \semsof{\mathtt{acyclic}~ \sf r \cup r^{-1}}$.
\end{lemma}
\begin{proof}
\begin{eqnarray*}
\semsof{\texttt{empty}~ \sf r} &=& \{X \in \E \mid \nexists (e_1,e_2) \in \sf r\} \reason{\defof \semsof{\texttt{empty}}} \\
&=& \{X \in \E \mid \forall e,e' \in E: \nexists (e,e') \in \sf r \} \\
&=& \{X \in \E \mid \forall e \in E: \nexists (e,e) \in \sf r \cup r^{-1} \} \\
&=& \semsof{\texttt{acyclic}~ \sf r \cup r^{-1}} \reason{\defof \semsof{\texttt{acyclic}}}
\end{eqnarray*}
\end{proof}

The \cref{lem:irracy,lem:emptyirr,lem:irrempty,lem:emptyacy} give us the following four rules:
\begin{rules}{Constraint Transformation}
\inferrule*[left=($a\rightarrow i$)]{\texttt{irreflexive}~ \sf r^+}{\texttt{acyclic}~ \sf r} \and
\inferrule*[left=($e \rightarrow i$)]{\texttt{irreflexive}~ \sf r.r^{-1}}{\texttt{empty}~ \sf r} \and
\inferrule*[left=($i \rightarrow e$)]{\texttt{empty}~ \sf r \cap \id}{\texttt{irreflexive}~ \sf r} \and
\inferrule*[left=($e \rightarrow a$)]{\texttt{acyclic}~ \sf r\cup r^{-1}}{\texttt{empty}~ \sf r}
\end{rules} 

These will be needed to eliminate the constraint from the term and to be able to continue with a relational inclusion proof. 


\subsection{Relational implications}\label{sec:implications}
The most basic rules are those which are always true for any relations. We list them here and sort them by the contributing operators. For commutative operators like union there is only one version of each rule since there is no different effect when interchanging the relations. Furthermore, in \Cref{sec:transformations} we state rules for commutativity and others. \\
Let $\Delta[t]$ be a relation term that includes the subterm $t$. 

\begin{rules}{No Operator}
\inferrule*[left=(reflexivity)]{\it true}{\sf r \subseteq r} \and
\inferrule*[left=(transitivity)]{\sf r \subseteq s \\ \rels \subseteq \relt}{\relr \subseteq \relt} \and
\inferrule*[left=(empty)]{true}{\0 \subseteq \relr} \and
\inferrule*[left=(full)]{true}{\relr \subseteq (E \times E)} \and
\inferrule*[left=(strength)]{{\sf r \subseteq} \Delta[\sf s] \\ \sf s \subseteq t}{{\sf r \subseteq} \Delta[\sf t]} \and
\inferrule*[left=(weak)]{\Delta[\sf r] \subseteq s \\ \sf t \subseteq r}{\Delta[\sf t] \subseteq s} 
\end{rules}
The rules without operator include some very basic facts like reflexivity, meaning that every relation is included in itself or transitivity, meaning that we can branch an inclusion into two inclusions using an intermediary term. With (\textsc{emtpy}) and (\textsc{full}) we capture the fact that the empty relation is included in any other relation and that every relation is included in the full relation. \\
(\textsc{strength}) and (\textsc{weak}) provide the possibility of strengthening the including term and weakening the included term with the help of an intermediate term. 

\begin{rules}{Union}
%\inferrule*[left=($\cup_{2R}$)]{\it true}{\sf r \subseteq r \cup s} \and durch (U3R) und (ref)
\inferrule*[left=($\cup_{L}$)]{\relr \subseteq \relt \\ \rels \subseteq \relt}{\relr \cup \rels \subseteq \relt} \and
\inferrule*[left=($\cup_{R}$)]{\sf r \subseteq s}{\sf r \subseteq s \cup t} \and
\end{rules}
We give two rules for the union operator, one for the included term and one for the including term.
($\cup_L$) helps resolve a union on the left side by branching the tableau. Logically, this equates to the claim that if two relations are included in a third, then the union of the two relations is also included.
For the included term we use the ($\cup_R$) rule to remove a term that is not needed anymore. This rule is not invertible and should only be used when the person applying it is certain about the inclusion. This rule is therefore impossible to implement in an automated tool, since it requires knowledge that the system does not have yet. A special case of the rule that could be implemented is 
\begin{mathpar}
\inferrule*[left=($\cup_R$alt)]{true}{\relr \subseteq \relr \cup \relt}
\end{mathpar}
This rule can be applied if we have transformed \Rels{} into the included term \relr. The disadvantage for human users would be that this carries the \relt{} term through the whole transformation. Both variants could be part of this proof system. Since we focus on improving the length of proofs and not automatisability, we chose the variant above.  
\begin{rules}{Intersection}
\inferrule*[left=($\cap_{L}$)]{\true}{\relr \cap \rels \subseteq \relr} \and 
\inferrule*[left=($\cap_{R}$)]{\relr \subseteq \rels \\ \relr \subseteq \relt}{\sf r \subseteq s \cap t} \and
\end{rules}
Our rules for intersections have a lot in common with the union rules. ($\cap_R$) branches the tableau correspondingly to the statement: if a relation is included in two others, then it is included in the intersection of the two. The rule for the included term is an axiom that captures the fact that an intersection is always included in the intersected terms. One could argue that to be consistent with the union rules, we could instead use the rule
\begin{mathpar}
\inferrule*[left=($\cap_L$alt)]{\relr \subseteq \relt}{\relr \cap \rels \subseteq \relt}
\end{mathpar}
While testing the rules, we have noticed that this does not save enough space in the proofs to justify having another rule that requires knowledge from the outside. In many cases the inclusion breaks down to a term $\relr \cap \rels \subseteq \relr$.
At the same time, the alternative rule offers the same capabilities and could therefore be used as well.
\begin{rules}{Concatenation}
%\textcolor{red}{
%\inferrule*[left=($._{trans}$)]{\sf r \subseteq \id}{\sf r \subseteq r.r} \and 
%\inferrule*[left=($._{RL}$)]{\sf \id \subseteq s}{\sf r \subseteq s.r} \and
%\inferrule*[left=($._{RR}$)]{\sf \id \subseteq s}{\sf r \subseteq r.s}} \and 
%\textcolor{red}{\inferrule*[left=($._{LR}$)]{\sf r \subseteq \id}{\sf s.r \subseteq s} \and
%\inferrule*[left=($._{LL}$)]{\sf r \subseteq \id}{\sf r.s \subseteq s}} \and
\inferrule*[left=($._{LR}$)]{\relr \subseteq \relr' \\ \rels \subseteq \rels'}{\relr.\rels \subseteq \relr'.\rels'}
\end{rules}
For concatenation we can use one general rule where we can construct many special cases with the help of the \id{} relation. Using the ($\id_{conc}$) rule that we introduce in a later section, we can construct cases for $\rels' = \id, \relr' = \id, \relr = \id$ or $\rels= \id$. This builds upon the fact that \id{} is a neutral element for concatenation. %$\relr.\rels \subseteq \relr'(.\id)$, $\relr.\rels \subseteq (\id.)\rels'$, $\relr(.\id) \subseteq \relr'.\rels$ and $(\id.)\rels \subseteq \relr'.\rels'$.
\begin{rules}{Transitive Closure}
\inferrule*[left=($+L$)]{\sf r \subseteq I \\ \sf r.I \subseteq I \\ \sf I \subseteq s}{\sf r^+ \subseteq s} %\and
%\inferrule*[left=($+_{LR}$)]{\sf r \subseteq s^+}{\sf r^+ \subseteq s^+} \and
%\inferrule*[left=($+_R$)]{\relr \subseteq \relI \\ \relI \subseteq \relI.\rels \\ \relI.\rels \subseteq \rels}{\relr \subseteq \Rels^+}
\end{rules}
For the transitive closure we need only one rule. In the case of $\relr \subseteq \rels^+$ we can unroll the transitive closure until we cover all of \relr. \\
The ($+_L$) rule uses an invariant \relI{} which is a fixed point under concatenation with \relr.
The choice of $\relI$ is not deterministic and can therefore not be automated. So far it has been sufficient to use $\relI = \Rels$ in most cases. \\

We can ignore the \textit{inversion} operator in the implications since according to \Cref{lem:inversion} every relation that features this operation can be transformed into an expression that features only inverted base relations. For this transformation we need the rules in \Cref{rule:inversion}. Similarly, we can ignore the Kleene-star (transitive closure) and the reflexive closure, since they are only unions of other relations according to their definition.


\begin{lemma}[Inversion Lemma]\label{lem:inversion}
Let $\relr$ be a relational term that features an inversion. There is an expression $\relr'$ that only features inversions that are applied to relations that cannot be decomposed further (in CAT: base relations) with $\semsof{\relr'} = \semsof{\relr}$. The proof can be found in the appendix (\Cref{sec:inversionproof}).
\end{lemma}


\paragraph{Derivation of ($\cup_{RL}$)}
While testing the proof system, this rule was repeatedly needed to shorten the proofs, eventhough it is not part of the rules in this section. In order to use the rule, we define the it here by showing it's construction through the other rules.

\begin{mathpar}
\inferrule*[left=($\cup_{RL}$),vcenter]{\sf r \subseteq s}{\sf r \cup r' \subseteq s \cup r'} = \quad
\inferrule*[left=(weak),vcenter]{
	\inferrule*[Left=($\cup_{L}$)]{
		\inferrule*[Left=($\cup_{R}$)]{\sf r \subseteq s}{\sf r \subseteq s \cup r'}
	}{\sf r \cup s \cup r' \subseteq s \cup r'}
	\\
	\inferrule*[Right=($\cup_{R}$)]{
		\inferrule*[Right=(refl.)]{\true}{\relr' \subseteq \relr'}
	}{\sf r' \subseteq s \cup r'}
}{\sf r \cup r' \subseteq s \cup r'}
\end{mathpar}

\subsection{Transformations}\label{sec:transformations}
Another part of the rules are transformations which are based on equalities of terms (e.g. $\relr~ \cup~ \rels= \rels~ \cup~ \relr$) instead of inclusion between terms. Therefore, the transformations can be used in either direction and terms on either side of the inclusion can be replaced.

The empty relation \0{} functions as a neutral element for union and absorbing element for concatenation and intersection, while the the full relation $(E \times E)$ is the neutral element for the intersection and the identity relation \id{} the neutral element for concatenation. This means, additionally, that \id{} is symmetric and transitive. Since this holds for any subrelation of \id{}, we can give generalizations of those rules for any relation \relr. For the following rules, let $\Omega[\dots]$ be a relational inclusion term.
\begin{rules}{Neutral and Absorbing Element}
\inferrule*[left=($\0_{\cup}$)]{\Omega[\sf r]}{\Omega[\sf \0 \cup r]} \and

The set theoretic operators $\cup$ and $\cap$ have the properties of distributivity, associativity and commutativity. Concatenation is associative and distributive.
\begin{definition}[Commutativity, Associativity, Distributivity]
Let $\circ$ and $\star$ be two operations on a set $S$ and $r,s \in S$.
\begin{eqnarray*}
\text{(Commutativity) }& r \circ s &= s \circ r \\
\text{(Associativity) }& r \circ (s \circ t) &= (r \circ s) \circ t \\
\text{(Distributivity) }& r \circ (s \star t) &= (r \circ s) \star (r \circ t)
\end{eqnarray*}
\end{definition}

To incorporate the capabilities these properties offer, they will be added to the set of rules here. For that purpose, let $\Omega[t]$ be an inclusion term that contains the subterm $t$.

\begin{lemma}\label{lem:++}
Let $\relr \subseteq (E \times E)$ be a relation. $\relr^+ = \relr^{+^+}$ holds.
\end{lemma}
\begin{proof} We use \Cref{def:alttc} for this proof:
\begin{eqnarray*}
\edgein \relr^+ &\Leftrightarrow & \exists n \in \N: \edgein \relr^n \\
&\Leftrightarrow & \exists k \in \N: \exists m_1,\dots m_k \in \N: \sum_{i=1}^k m_k = n \land \edgein \relr^{m_1}.\dots.\relr^{m_k}\\
&\Leftrightarrow & \exists k \in \N: \edgein \relr^{+^k} \\
&\Leftrightarrow & \edgein \relr^{+^+}
\end{eqnarray*}

\end{proof}

\begin{lemma}\label{lem:+cap+}
Let $\relr,\rels \subseteq (E \times E)$ be relations. Then $\sf r^+ \cap s^+ = (r^+ \cap s^+)^+$ holds. 
\end{lemma}
\begin{proof} The $\impl$ direction is very intuitive and easy to show:
\begin{eqnarray*}
\edgein \relr^+ \cap \rels^+ &\Leftrightarrow & \edgein (\relr^+ \cap \rels^+)^1 \\
&\impl & \exists n \in \N: \edgein (\relr^+ \cap \rels^+)^n \\
%(e,e') \in {\sf r^+ \cap s^+} &\Leftrightarrow & (e,e') \in {\sf r^+} \land (e,e') \in {\sf s^+} \reason{\defof \cap} \\
%&\Leftrightarrow & \exists n \in \N: e=e_1 \land e'=e_n \land \forall i\in [1,n]: (e_i,e_{i+1}) \in \relr \\
%&&\land \exists m \in \N: e=e_1 \land e'=e_m \land \forall i\in [1,m]: (e_i,e_{i+1}) \in \rels \reason{\defof +}\\
%&\Leftrightarrow &  \edgein {\sf (r^+ \cap s^+)} \\
&\Leftrightarrow & (e,e') \in {\sf (r^+ \cap s^+)^+} \reason{\Cref{def:alttc}}
\end{eqnarray*}
For the other direction, we need to prove that $\edgein (\relr^+ \cap \rels^+)^n \impl \edgein (\relr^+ \cap \rels^+)$. 
\begin{eqnarray*}
\edgein (\relr^+ \cap \rels^+)^n &\Leftrightarrow & \exists n\in \N: e=e_1 \land e'=e_n \land \forall i \in [1,n]: (e_i,e_{i+1}) \in \relr^+ \cap \rels^+ \\
& \impl & \forall i \in [1,n]: (e_i,e_{i+1}) \in \relr^+ \land (e_i,e_{i+1}) \in \rels^+ \\
& \impl & \edgein \relr^{+^+} \land \edgein \rels^{+^+} \\
& \Leftrightarrow & \edgein \relr^+ \land \edgein \rels^+ \\
& \Leftrightarrow & \edgein \relr^+ \cap \rels^+
\end{eqnarray*}
\end{proof}


\begin{lemma}\label{lem:*cup*}
Let $\relr,\rels \subseteq (E\times E)$ be relations. Then $\sf (r^*.s^*)^* = (r \cup s)^*$ holds.
\end{lemma}
\begin{proof}
\begin{itemize}
\item[$\subseteq$:] For any $(e_1,e_h) \in \sf (r^*.s^*)^*$ there exist $k,m_1,\dots m_k,n_1,\dots n_k \in \N_0$ with $(e_1,e_h) \in {\sf r}^{m_1}.{\sf s}^{n_1}. \dots {\sf r}^{m_k}.{\sf s}^{n_k}$.
Consequently, there need to be $(e_1,e_{2}),\dots ,(e_{h-1},e_{h})$ where every $(e_i,e_{i+1})$ is either in \textsf{r} or \textsf{s} and $h = \sum_{j=1}^k m_j + n_j$.
Accordingly, $(e_1,e_h)$ is in $\sf (r \cup s)^h$ and thus $(e_1,e_h) \in \sf (r \cup s)^*$.
\item[$\supseteq$:] We can use other transformations to prove this direction.
\begin{eqnarray*}
\sf (r^*.s^*)^* &=& \sf (r^*.s^*)^+ \cup \id \\
&=& \sf ((r^+ \cup \id).(s^+ \cup \id))^+ \cup \id \\
&=& \sf (r^+.s^+ \cup r^+.\id \cup \id.s^+ \cup \id.\id)^+ \cup \id \\
&=& \sf (r^+.s^+ \cup r^+ \cup s^+ \cup \id)^+ \cup \id \\
&\supseteq & \sf (r \cup s)^+ \cup \id \\
&=& \sf (r \cup s)^*
\end{eqnarray*}
\end{itemize}
\end{proof}


\begin{lemma}\label{lem:*.*}
Let $\relr \subseteq (E\times E)$ be a relation. Then $\sf r^* = r^*.r^*$ holds. \end{lemma}
\begin{proof}
\begin{itemize}
\item[$\subseteq$:] For any $(e,e') \in \sf r^*$ it holds that $(e,e') \in \sf r^*.\id$ and hence $(e,e') \in \sf r^*.r^*$. \\
\item[$\supseteq$:] For any $(e,e') \in \sf r^*.r^*$ there exist $n,m \in \N_0$ with $(e,e') \in {\sf r}^n.\relr^m$. Since ${\sf r}^n.\relr^m$ is the same as $\relr^{n+m}$, it holds that $(e,e') \in {\sf r}^{n+m}$ and therefore $(e,e') \in {\sf r}^*$.
\end{itemize}
\end{proof}

\subsection{Relation-specific Rules}\label{sec:relationspecific}
Memory Consistency Models are defined on a group of relations. Each of them comes with certain properties that need to be recognized in the rules. In \cite{Gru+26} this concept is called \textit{Hypotheses}. \\
The base relations \loc{} and \ext{} are symmetric, meaning that for every $(e,e')$ in the relation, $(e',e)$ is in the relation too. For \po, \co{} and \loc{} it holds that they are transitive, meaning for every $(e,e'),(e',e'') \in R: (e,e'') \in R$. 
\begin{rules}{Base Relation Properties}
\inferrule*[left=($\loc_{symm}$)]{\it true}{\loc^{-1} \subseteq \loc} \and
\inferrule*[left=($\ext_{symm}$)]{\it true}{\ext^{-1} \subseteq \ext} \and
\inferrule*[left=($\po_{trans}$)]{\true}{\po .\po \subseteq \po} \and
\inferrule*[left=($\co_{trans}$)]{\true}{\co .\co \subseteq \co} \and
\inferrule*[left=($\loc_{trans}$)]{\true}{\loc .\loc \subseteq \loc} 
\end{rules}
Since inversion is only applied to base relations, the $(-1_{elim})$ rule is placed in this section. In theory it could be applied to any relation. The rule uses the fact that $\sf r.r^{-1}$ and $\sf r^{-1}.r$ include a part of \id{} that covers all events that occur on either end of the edges in \relr.
\begin{rules}{Inversion Elimination}
\inferrule*[left=($-1_{elim}$)]{\true}{\sf r \subseteq r.r^{-1}.r} 
\end{rules}
\begin{proof} Here we need to prove the implication, since it is not a given propertiy from the definition of CAT.
\begin{eqnarray*}
\edgein \relr &\impl & \edgein \Relr \land \egdein \relr^\inv \land \edgein \relr \\
&\impl & \edgein \relr.\Relr^\inv.\relr
\end{eqnarray*}
\end{proof}
As we have described in \Cref{sec:notation}, the relations \relW~ and \relR~ can be used to restrict relations to groups of events. Some base relations are already restricted. The \rf{} relation only connects writes to reads and the \co{} relation only connects writes to later writes.
Besides this we use some rules to handle set restrictions like \relW~ and \relR~ themselves.
For this purpose let $A \subseteq E$ be a set of events. 
\begin{rules}{Write and Read Events}
\inferrule*[left=(A)]{\true}{[A] \subseteq \id} \and
\inferrule*[left=(WR)]{\true}{\sf [W].[R] \subseteq \0} \and
\inferrule*[left=(RW)]{\it true}{\sf [R].[W] \subseteq \0} \and
\inferrule*[left=(\rf)]{\it true}{\sf \rf = [W].\rf .[R]} \and
\inferrule*[left=(\co)]{\it true}{\sf \co = [W].\co .[W]} 
\end{rules}
The last part of relation-specific rules concerns inclusions between base relations like the one between \textsf{ppo} and \po. The inclusion between \rf{} and \loc{} is based on the fact, that \rf{} relates two events on the same memory location, namely one read and the write that provided the value in that location. Since \loc{} includes connections between all events on the same location, every entry of \rf{} needs to be in \loc{}. The same holds for the consecutive writes on the same location in \co{}. 
\begin{rules}{Inclusions}
\inferrule*[left=(\textsf{ppo})]{\true}{\textsf{ppo} \subseteq \po} \and

\inferrule*[left=(\text{\rf\loc})]{\true}{\rf \subseteq \loc} \and
\inferrule*[left=(\text{\co\loc})]{\true}{\co \subseteq \loc} 
\end{rules}

\section{Soundness}\label{sec:soundness}
To prove soundness of the proof system, soundness of all rules is necessary. Most of the rules can easily be proven through logical implications. For strengthening and weakening, the rules need to be proven with monotonicity of each operator. This follows in the next subsections.
The transformations are proven in the corresponding section or in the appendix. 

Using the \Cref{lem:implications,lem:bmono,lem:umono}, it is clear that every proof $\prf$ that uses only these rules is sound and therefore the inclusion at the root of $\prf$ holds.

\subsection{Weakening and Strengthening}
To prove the weakening and strengthening rules, we need to prove monotinicity for each operator. Starting with the binary operators, this guarantees that for union, intersection and concatenation, it holds that replacing a subterm with a stronger one will not weaken the term and replacing a subterm with a weaker one will not strengthen the term.
\begin{lemma}[Binary Monotinicity]\label{lem:bmono} Let $\star: (E\times E) \times (E \times E) \rightarrow (E \times E)$ be any binary operator in rational CAT. It holds that if $\sf r \subseteq s$, then $\sf t \star r \subseteq t \star s$ and $\sf r \star t \subseteq s \star t$ \end{lemma} 
\begin{proof}
For proving monotonicity, the lemma needs to be shown for every binary operator in rational CAT.
We will start with the union operator:
\begin{eqnarray*}
(e,e') \in \sf t \cup r &\impl & (e,e') \in \relt \lor (e,e') \in \relr \reason{\defof \rel_1 \cup \rel_2} \\
& \impl & (e,e') \in \relt \lor (e,e') \in \sf s \reason{r \subseteq s} \\
&\impl & (e,e') \in \relt \cup \rels \reason{\defof \rel_1 \cup \rel_2}
\end{eqnarray*}
Just as simple as for union is the proof for intersection:
\begin{eqnarray*}
(e,e') \in \sf t \cap r &\impl & (e,e') \in \relt \land (e,e') \in \relr \reason{\defof \rel_1 \cap \rel_2}\\
& \impl & (e,e') \in \relt \land (e,e') \in \sf s \reason{r \subseteq s} \\
&\impl & (e,e') \in \relt \cap \rels \reason{\defof \rel_1 \cap \rel_2}
\end{eqnarray*}
Since the first two operators were commutative, the order of the relations was not important. As this is not the case for concatenation, there needs to be a distinction between $\sf t.r$ and $\sf r.t$
\begin{eqnarray*}
(e,e'') \in \sf t.r &\impl & (e,e') \in \relt \land (e',e'') \in \relr \reason{\defof \rel_1.\rel_2}\\
& \impl & (e,e') \in \relt \land (e',e'') \in \sf s \reason{r \subseteq s} \\
&\impl & (e,e'') \in \relt.\rels \reason{\defof \rel_1.\rel_2}
\end{eqnarray*}
\begin{eqnarray*}
(e,e'') \in \sf r.t &\impl & (e,e') \in \relr \land (e',e'') \in \relt \reason{\defof \rel_1.\rel_2} \\
& \impl & (e,e') \in \rels \land (e',e'') \in \sf t \reason{r \subseteq s} \\
&\impl & (e,e'') \in \rels.\relt \reason{\defof \rel_1.\rel_2}
\end{eqnarray*}
This proves monotonicity for every binary operator of rational CAT.
\end{proof}
The unary operators of rational CAT are inversion, reflexive closure, transitive closure and reflexive-transitive closure. The next step is to show monotonicity for these aswell.
\begin{lemma}[Unary Monotonicity]\label{lem:umono} Let $f:(E\times E) \rightarrow (E \times E)$ be a unary operator (function) of rational CAT. It holds that for any $\relr,\rels \subseteq E \times E$, if $\sf r \subset s$, then $f(\relr) \subseteq f(\rels)$.
\end{lemma}
\begin{proof}
The first unary operator of rational CAT will be inversion:
\begin{eqnarray*}
(e,e') \in \relr^{-1} &\impl & (e',e) \in \relr \reason{\defof \rel^{-1}}\\
&\impl & (e',e) \in \sf s \reason{\sf r \subseteq s} \\
&\impl & (e,e') \in \rels^{-1} \reason{\defof \rel^{-1}}
\end{eqnarray*}
Next up is the transitive closure:
\begin{eqnarray*}
(e,e') \in \relr^+ &\impl & \exists n \in \N: e=e_1 \land e' = e_n \land \forall i \in [1,n]: (e_i,e_{i+1}) \in \relr \reason{\defof \rel^+} \\
&\impl & \exists n \in \N: e=e_1 \land e' = e_n \land \forall i \in [1,n]: (e_i,e_{i+1}) \in \rels \reason{\sf r \subseteq s} \\
&\impl & (e,e') \in \rels^+ \reason{\defof \rel^+}
\end{eqnarray*}
For the unary operators reflexive closure the monotonicity is given through its definition and \Cref{lem:bmono}:
\[\relr? = \relr \cup \id \subseteq \rels \cup \id = \rels?\]
For the reflexive-transitive closure the monotonicity is given through their definition and the monotonicity of the union operator and the transitive closure:
\[\relr^* = \relr^+ \cup \id \subseteq \rels^+ \cup \id = \rels^*\]
\end{proof}
With \Cref{lem:bmono,lem:umono} at hand, we can now prove the weakening and strengthening rules.
\begin{itemize}
\item $(\textsc{weak}):~ \Delta[\relr] \subseteq \rels \land {\sf t \subseteq r} \impl \Delta[\relt] \subseteq \rels$
\begin{eqnarray*}
(e,e') \in \Delta[\relt] &\impl & (e,e') \in \Delta[\relr] \reason{\text{\Cref{lem:bmono,lem:umono}, } \sf t \subseteq r} \\
& \impl & (e,e') \in \rels \reason{\Delta[\relr] \subseteq \rels}
\end{eqnarray*}
\item $(\textsc{strength}):~ \relr \subseteq \Delta[s] \land \rels \subseteq \relt \impl \relr \subseteq \Delta[\relt]$
\begin{eqnarray*}
\edgein \relr &\impl & \edgein \Delta[\rels] \reason{\relr \subseteq \Delta[\rels]} \\
&\impl & \edgein \Delta[\relt] \reason{\text{\Cref{lem:bmono,lem:umono}, } \rels \subseteq \relt}
\end{eqnarray*}
\end{itemize}


\subsection{Proving Soundness of the Rules}\label{sec:prvrelimp}

\begin{lemma}\label{lem:rulessoundness}
For every rule from the \Cref{sec:implications,sec:transformations} it holds that the premise implicates the conclusion and the rule is therefore sound.
\end{lemma}
\begin{proof}
For the rules in \Cref{sec:implications} we can use \Cref{lem:implications}. For the rules in \Cref{sec:transformations} the argument is that the Rules "Neutral and Absorbing Element", "Operator Properties" and "Operator Definitions" are based on the definitions of the relations and operators and require no proof. For the "Transitive Closure Simplification Rules", \Cref{lem:++,lem:+cap+,lem:*cup*,lem:*.*} show their correctness as does \Cref{lem:inversion} for the "Inversiontransformations".
\end{proof}

\begin{theorem}[Soundness]\label{thm:soundness}
Let $\relr, \rels \subseteq (E\times E)$ be two relational terms. If there is a proof $\prf$ for the inclusion $\relr \subseteq \rels$, then the inclusion holds.
\end{theorem}
\begin{proof}
Let $\prf_n$ be any proof for a relational inclusion $\Relr \subseteq \rels$ of length $n \in \N$, meaning that $\prf_n$ uses $n$ rules in the longest branch. We prove the soundness of $\prf$ via induction on $n$. To that end, let $n=1$. $\prf_1$ only uses one rule and from \Cref{lem:rulessoundness} we know that this rule is sound.\\
We assume as induction hypothesis that any $\prf_n$ is sound for a particular $n$. \\
A proof of length $n+1$, which we call $\prf_{n+1}$ consists of a proof of length $n$ and one more rule that has $\relr \subseteq \rels$ as conclusion. By the induction hypothesis we know the first part of the proof to be sound and by \Cref{lem:rulessoundness} this also holds for the last rule. 
Hence, $\prf_{n+1}$ is sound and by the principle of the induction this holds for every proof $\prf$ of any length.
\end{proof} 


\subsection{Soundness for MCM Inclusion Proofs}
We have proven soundness of our proof system for arbitrary relations $\relr \subseteq \rels$.
To fulfill the goal of this thesis, we still need to prove soundness for memory consistency models.
\begin{theorem}[MCM Soundness]
Let $M_1 = \bangle{constraint}~ \relr_1$, $M_2 = \bangle{constraint}~ \relr_2$ be two memory consistency models characterized by CAT expressions. If there is a CAT inclusion proof $\prf^{CAT}$ for the inclusion $\semsof{M_1} \subseteq \semsof{M_2}$ then the inclusion holds.
\end{theorem}
\begin{proof}
We have a CAT inclusion proof $\catprf$ for the inclusion $\semsof{M_1} \subseteq \semsof{M_2}$ that uses a relational inclusion proof $\prf$. 
From \Cref{lem:irracy,lem:emptyirr,lem:irrempty,lem:emptyacy} we know that any two CAT expressions can be transformed to use the same constraint. The constraint transformation rules thus yield $M_1' = \bangle{constraint}~ \relr_1', M_2' = \bangle{constraint}~ \relr_2'$ with $\semsof{M_1} = \semsof{M_1'}$ and $\semsof{M_2} = \semsof{M_2'}$ where the constraints are the same. \\
With \Cref{lem:elimination} we know that if $\relr_2' \subseteq \relr_1'$ holds, then the CAT inclusion holds as well. Since any CAT inclusion proof $\catprf$ contains a relational inclusion proof $\prf$ and we know from \Cref{thm:soundness} that these are sound, the inclusion $\relr_2' \subseteq \relr_1'$ holds. Together with \Cref{lem:elimination} it is clear that $\semsof{M_1} = \semsof{M_1'} \subseteq \semsof{M_2'} = \semsof{M_2}$ holds and hence the CAT inclusion proof $\catprf$ is sound.
\end{proof}

\section{Completeness}\label{sec:completeness}

\begin{theorem}[Completeness]
Let $M_1 = \bangle{constraint}~ \Rels, M_2 = \bangle{constraint}~ \relr$ be two memory consistency models, defined as CAT expressions. 
If the inclusion $\semsof{M_1} \subseteq \semsof{M_2}$ holds, there exists a proof $\mathcal{P}^{CAT}$ for it.
\end{theorem}

To prove the completeness of this proof system on the rational CAT fragment we will transform any proof of a relational inclusion by Grünke et al. \cite{Gru+26}, where completeness was proven, into one of ours.  
Since RAT-CAT-SAT argues directly about events and we do not, we lose some expressiveness in comparison to Grünke et al.. Therefore, we reduce the number of proofs that RAT-CAT-SAT can express to only those that show inclusions between relations. \\
We can justify this with the Lemmata in \Cref{sec:constraints}. Any inclusion between CAT expressions can be transformed into an inclusion between two relations where the CAT inclusion is true if and only if the relational inclusion holds.
Since the procedure of Grünke et al. \cite{Gru+26} is complete for any unsatisfiable cube, a proof $\pi$ has to exist and if any proof of a relational inclusion that is confined to the syntax of rational CAT can be translated into a relational inclusion proof $\prf_\pi$ in our system, then we can construct a proof for any CAT inclusion. \\
The approach of Grünke et al. transforms an inclusion of the form $\relr \subseteq \rels$ into a logical formula $\phi_{\relr \subseteq \rels} = \phi_{\relr} \land \neg \phi_{\rels}$ where the unsatisfiability of the formula corresponds to the inclusion term being true. Unsatisfiability in \cite{Gru+26} is defined with the help of $\Sigma$-structures, which are basically the domain of events and an interpretation of the sets, functions and relations. Furthermore, $\mathcal{T}_\Sigma$ is the set of all $\Sigma$-structures and $\mathcal{T}_\Sigma$-unsatisfiability is defined as there being no $\Sigma$-structure that satisfies the formula.
Hence, the Theorem to be proven is this:
\begin{theorem}\label{thm:satinc}
If a RAT-CAT formula $\phi_{\relr \subseteq \rels}$ is $\mathcal{T}_\Sigma$-unsatisfiable and it exists a RAT-CAT proof tableau $\pi$, then there exists a relational inclusion proof $\prf_\pi$ for $\sf r \subseteq s$
\end{theorem}


%To prove \Cref{thm:satinc}, for any proof $\pi$ in \cite{Gru+26} we need to construct an equivalent proof $\mathcal{P}_\pi$.
%With the transformation of the expressions into logical formulas, the inclusion turns into an implication and then into a conjunction where the formula for the right-hand side of the inclusion is negated. Since we want to preserve the form of the inclusion in our system, we cannot follow this step, but need to keep in mind that we still need to distinguish the terms of the inclusion.
%To have a more intuitive way of translating the formulas into relational inclusion terms, we use a intermediate step. The inclusion $\relr \subseteq \rels$ that our system uses can be written as $\relr~ \cap \sim \rels \subseteq \0$. Note that we allow complements for this intermediate step only and use them to give a better intuition for how the behavior of the RAT-CAT-SAT rules corresponds to our rules. The term $\relr~ \cap \sim \rels \subseteq \0$ is much closer syntactically to $\varphi_\relr \land \neg \varphi_{\rels}$ being unsatisfiable.


The proof system of Grünke et al. starts with the formula $\phi_{\relr \subseteq \rels} = \phi_\relr \land \neg \phi_\rels$ and transforms it until the tableau is \textit{closed} with a set of rules. 
A closed tableau is one where every branch in it is closed, meaning that every branch is either infinite or contains $\bot_0$. Here, $\bot_0$ functions as a symbol representing a contradiction and essentially meaning \textit{false}. \\ 
The decomposition of the formula $\phi_\relr$ in \cite{Gru+26} results in a number of atomic predicates ($e \in A, \edgein \relr, e = e', e \neq \emptyset$) that events need to fulfill to form an edge in \relr. The negated rules only decompose the the negative part of the formula $\neg \varphi_\rels$ to give predicates that describe the complement of \rels. If there exist events that fulfill all of these properties, then there exists a counterexample to the inclusion.
Hence, unsatisfiability of the formula is equivalent to the inclusion being true. \\
Furthermore, these inclusions have a standard form as a RAT-CAT formula: An inclusion $\relr \subseteq \rels$ is
\[\phi_{\relr \subseteq \rels} = \phi_\relr \land \neg \phi_\rels = (e_1.\relr \cap e_2) \neq \emptyset \land \neg((e_1.\rels \cap e_2) \neq \emptyset)\]
We call this the \textit{Relational Inclusion Standard Form (RISF)}.
We prove completeness by showing that for every formula $\phi_{\relr \subseteq \rels}$ in RISF that has a proof $\pi$, $\relr \subseteq \Rels$ can be proven by $\prf_\pi$ in our system. \\
Besides the RISF we can also assume that $\pi$ is the shortest proof for unsatisfiability of $\phi_{\relr \subseteq \rels}$. In Grünke et al.'s system, rules can be applied unnecessarily for example when for $\relr \subseteq \relr \cup \rels$ the term $\rels$ is decomposed.
Assuming $\pi$ to be the shortest proof will give us the information that every applied rule makes progress towards a contradiction and restricts the number of cases we need to cover for our translation. It also means, that whenever a rule is applied to a certain predicate, the decomposition of that predicate will yield the contradiction to close the branch. \\
Furthermore, we can assume that base sets will only be used in cross products to form relations according to the syntax of CAT (see \Cref{fig:cat}).
The notation from \cref{sec:notation} can be written as $[A].\relr.[B] = \relr \cap (A \times B)$.

To translate $\pi$ into $\prf_\pi$, we will translate each rule of Grünke et al. that can be applied to a formula in RISF. Moreover, we will show that every branch in $\pi$ will have an equivalent branch in $\prf_\pi$ and that whenever $\pi$ splits a predicate, $\prf_\pi$ can take equivalent action.
Splitting predicates refers to rules that have a non-atomic literal $l[\dots]$ in the premise and two non-atomic terms $l[\dots], l[\dots]$ in the conclusion. The context of $l$ can be taken into both predicates. 
An example for splitting predicates is the ($\neg {\cup_2}L$) rule:
\begin{mathpar} \inferrule*[left=($\neg {\cup_2}L$)]{\Gamma, \neg p[e.(\relr_1 \cup \relr_2)]}{\Gamma, \neg p[e.\relr_1], \neg p[e.\relr_2]}
\end{mathpar}
This only refers to non-atomic predicates, since atomic predicates fulfill a very different role. In positive reasoning, atomic predicates describe the structure of the term even after it has been decomposed. In negative reasoning, the atomic predicates will in most cases yield a contradiction.
As they cannot be decomposed any further, they are not important in negative reasoning when they don't imply a contradiction yet. Then, the contradiction will come from a predicate that still has to be decomposed. \\
The splitting and branching in \cite{Gru+26} is furthermore important to provide an assumption that the authors make. They assume their predicates to be union-free and Kleene-star-free. As we will see, this is reached by applying rules that split predicates and branch the proof.

\begin{lemma}[Splitting Lemma]\label{lem:splitting}
Whenever $\pi$ splits a non-atomic literal $l$ into the non-atomic literals $l_1, l_2$ (there are only rules that split into two non-atomic literals), $\prf_\pi$ can justify the separate decomposition of both literals with a union.
\end{lemma}
\begin{proof}
In $\pi$ many rules split a literal into multiple ones. The atomic literals $(\neg) e_1 = e_2, e \in A, (e,e') \in \relr$ and $e \neq \emptyset$ keep information about the relational term that has already been decomposed and are not of concern for this lemma.
We only look at the non-atomic literals where one literal turns into two new ones.
The rules that we care about are the following: 
\[(\neg aL), (\neg {*}L), (\neg {\cup_2}L), (\neg {\equiv}L), (\neg A), (\neg \cup_1), (\neg \top_1)\]
Since this only appears in negative reasoning, we can assume that the literal in the premise has the form $\neg p[\dots]$. Furthermore, this gives us the knowledge that only the including term $\rels$ in $\relr \subseteq \rels$ is concerned in $\prf_\pi$. \\
Two literals in the same cube are always connected by a conjunction, meaning that both have to be true in order to fulfill the cube. Seeing that $\pi$ will show the unsatisfiability of the cube, the conjunction can be interpreted as two options to create a contradiction. This translates to being two terms that can prove the inclusion $\relr \subseteq \rels$. In relational inclusion proofs the equivalent term would be a union $\relr \subseteq \rels_1 \cup \rels_2$ where each $\rels_i$ represents one of the literals.
We can make this more explicit: The rules we consider all have the form 
\begin{mathpar}
\inferrule*[]{\Gamma, \neg p[\rels]}{\Gamma, \neg p[\rels_1], \neg p[\rels_2]}
\end{mathpar}
where $\Gamma$ are more predicates which may describe more including or included relational terms and $p[\dots]$ is the context of $\Rels$. For the translation in our system, we denote the context as $\Delta[\dots ]$ and let $\relr_\Gamma$ and $\relt_\Gamma$ be the included and including terms described by $\Gamma$ respectively. Given these translations, we get: 
\begin{mathpar}\inferrule*[]{\relr_\Gamma \subseteq \relt_\Gamma \cup \Delta[\rels_1] \cup \Delta[\rels_2]}{\relr_\Gamma \subseteq \relt_\Gamma \cup \Delta[\rels]}
\end{mathpar}
If there is a way to get $\Delta[\rels_1 \cup \rels_2]$ from $\Delta[\rels]$ then we can use ($\cap_{\cup dist}$), ($._{\cup distL}$) and ($._{\cup distR}$) to factor out the union from $\Delta$.
Now, we only need to show that we can get $\rels_1 \cup \rels_2$ from $\rels$ with our rules for every splitting rule in \cite{Gru+26}. \\

($\neg {*}L$) has $\Gamma, \neg p[e.\Rels^*]$ as premise and $\Gamma, \neg p[e], p[(e.\rels).\rels^*]$ as a conclusion. With the ($*$) rule, we can get $\id \cup \rels^+$ inside any context and with ($+$) we can transform $\rels^+$ to $\rels.\rels^*$. \\

($\neg {\cup_2}L$) has $\neg p[e.(\rels_1 \cup \rels_2)]$ in the premise and $\neg p[\Rels_1], \neg p[\Rels_2]$ in the conclusion. Thus, the term in the premise already has the desired form and no more transformations are necessary. \\

($\neg \cup_1$) has $\neg p[A_1 \cup A_2]$ in the premise and $\neg p[A_1], \neg p[A_2]$ in the conclusion. The notion of sets of events in \cite{Gru+26} is that it can be either a base set or the possible results of $e.\rels$. In the latter case, there must have been a union of relations in the term and we can use the procedure for the ($\neg {\cup_2}L$) rule.
In the former case, we know that base set appear in rational CAT only in cross products $A \times B$. So if the rule is applied and we have $(A_1 \cup A_2) \times B$, we can use the ($\times_{\cup distL}$) and ($\times_{\cup distR}$) rules to factor out the union and then proceed as for ($\neg \cup_2 L$). \\

($\neg aL$) has $\neg p[e_1.\rels], (e_1,e_2) \in \Rels$ in the premise and $\neg p[e_1.\rels], \neg p[e_2], (e_1,e_2) \in \Rels$ in the conclusion. The predicate $(e_1,e_2) \in \rels$ tells us that the relation $\Rels$ appears at the same position in the included term. Therefore, the rule will eliminate that relation in one of the resulting terms and keep it in the other. In \Cref{sec:negreasoning} we will see how exactly the rule handles this. As far as the splitting is concerned, we can simply duplicate the term $\rels$ with (\textsc{strength}), ($\cup_L$) and (\textsc{reflexivity}) and continue with the procedure from \Cref{sec:negreasoning} in only one of the terms. \\

($\neg A$) has $\neg p[A], e \in A$ in the premise and $\neg p[A], \neg p[e], e \in A$ in the conclusion. Again, as both terms are semantically the same, we can duplicate it in our system.
($\neg {\equiv}L$) has $\neg p[e_1], e_1=e_2$ in the premise and $\neg p[e_1], \neg p[e_2], e_1=e_2$ in the conclusion. It is very clear that this is a duplication. Later in this thesis (Again \Cref{sec:negreasoning}) we will argue that this rule is only applied when there is an intersection $\rels \cap \Rels'$ and the wrong term's event is carried along and that we can prevent this in our system with the commutativity rule. Equally, we could duplicate the term and use commutativity to create $(\rels \cap \Rels') \cup \rels' \cap \rels$.\\

($\neg \top_1$) has in it's premise $\neg p[\top_1]$ and in it's conclusion $\neg p[\top_1],\neg[e]$. This is basically the same case as ($\neg A$) since $\top_1$ is the full set of events ($E$ in our system) and $e$ is any event which is automatically in $\top_1$.
\end{proof}


\begin{lemma}[Branching Lemma]\label{lem:branching}
Whenever $\pi$ creates new branches like this:
\begin{mathpar} \inferrule*[left=$\pi$:]{\pi_1}{\C_1 \\ \mid \\ \C_2}
\end{mathpar}
where $\pi_1$ is the preceding proof of a branching rule and $\C_1$ and $\C_2$ are the first cubes after it and describe counterexamples to the inclusion terms $\Omega_1$ and $\Omega_2$, $\prf_\pi$ can create new branches for these terms.
\end{lemma}

\begin{proof}
For unions and Kleene-stars the positive rules create new \textit{branches}. To prove the lemma and emulate the behavior of $\pi$, the branching in $\prf_\pi$ needs to have the same effect on the semantics.
A union in the positive term essentially means, that a counterexample to the inclusion needs to be in one of the unioned relations and to prove the inclusion true it has to be shown that there cannot be a counterexample in either.
This corresponds closely to branching a union in the included term with ($\cup_L$), because it argues that both subrelations need to be included, i.e. there is no counterexample to the induction in either.
For the Kleene-star rule ($*L$) the branching is based on a union too, since $\relr^* = \id \cup \relr^+$. \\
In negative reasoning, branching occurs whenever there is an intersection or a cross product.
For intersections, the ($\cap_2L$) rule distributes the preceding event to both terms on either side of the intersection. Those two terms will be decomposed into the events $f_1,f_2$. This is only possible, if either relation is the full relation or if they exist at the same position in the included term.
Depending on whether this is the outermost operator of that literal, either the ($\neg {\cap_1}R$) or the ($\neg eL$) rule can be applied. The intuition for the former case is, that if both branches end in \false, the counterexample candidate would have to be in both terms and therefore in the intersection. This would mean, that it is no counterexample. If one or both branches cannot be closed, the candidate is only in one term or none and can therefore be a counterexample to the inclusion. \\
In the relational proof, the premise of ($\neg {\cap_1}$) equates to a term $\relr \subseteq (\rels \cap \rels')$. Here, we can use the ($\cap_R$) rule, branching the term into $\relr \subseteq \rels$ and $\relr \subseteq \rels'$. \\
In the case of the ($\neg eL$) rule, the intersection can be anywhere in the including term.
From RISF and the rules of Grünke et al., we can deduce that the proof $\pi$ resolves the including term from left to right. Since the rules for decomposing terms require a concatenated event, and in RISF an event is concatenated only at the left end, we can assume that only terms concatenated on the right side are appended to the current term. This could only change due to an inverted term. However, since this must be a base relation according to \Cref{lem:inversion}, the ($\neg aR$) rule can also be applied after applying the ($\cdot^\inv L$) rule. More details on this follow in \Cref{sec:negreasoning}. \\
Furthermore, we know from \Cref{lem:splitting} that the predicate will be union-free and we can assume that there is no intersection around this one, since in that case the rule ($\neg eL$) should have been applied to that term before. Then, $\pi$ would have created a new branch where the ($\neg \cap_1 L$) rule would be applicable. \\
Following our arguments, we know that the current intersection term cannot have a concatenation on the left side, cannot be part of a union or an intersection and therefore has to be of the form $\neg p[(\rels \cap \Rels').\relt]$. \\
As both branches will be closed in the future and could not be closed before, both terms that result from the branching have the potential for a contradiction. \\
For the $\Gamma, \neg f_1 \cap f_2 \neq \emptyset$ branch it holds that it will yield the predicate $\neg f_1 = f_2$ and as this predicate will induce a contradiction, the predicate $f_1 = f_2$ has to exist in the cube, originating from positive reasoning. Since the events mark the position in the relational term, this implicates that the exact same intersection term has to exist at the same position in the included term.\\
Therefore we can apply the ($._{LR}$) rule in our system:
\begin{mathpar}
\inferrule*[left=($._{LR}$)]{\relr_\Gamma \subseteq \relt_\Gamma \\ \rels \cap \rels' \subseteq \rels \cap \rels'}{(\rels \cap \rels').\relr_\Gamma \subseteq (\rels \cap \rels').\relt_\Gamma}
\end{mathpar}

If $\rels = (A_1 \times A_2)$ with $A_1,A_2 \subseteq E$ and the ($\neg \times L$) rule is used in $\pi$, then the proof branches into one cube containing $\neg e_1 \cap A_1 \neq \emptyset$ and one cube containing $\neg p[A_2]$. The former predicate can only be transformed with ($\neg A$) and ($\neg\cap_e$) into the atomic predicate $\neg e_1 = f_1$, ending the decomposition. This requires the predicate $f_1 \in A_1$ from positive reasoning, meaning that $A_1$ exists at the same position in the included term. Because the branch needs to be closed through these predicates and the only new predicate is $\neg e_1 = f_1$, there has to be the predicate $e_1 = f_1$ in the cube to create a contradiction and close the branch with the ($\bot_0$) rule. \\
The latter predicate retains the context and after applying ($\neg A$) to it, yields a positive event $f_2$ for the decomposition as demanded by \Cref{lem:decomposition}. Once more, this requires a predicate $f_2 \in A_2$ originating from the positive reasoning. \\
A different way would be to use the ($\neg_{\cdot 1,2}R$) rule which can be applied using all concatenated relations as $\relr$ (\textcolor{red}{\Relr{}} in the context of the rule from \cite{Gru+26}) and $e_2$ as the intersected event $e$. Either way, the set would have to be decomposed into an event and therefore we assume the first rule to be applicable. \\
Essentially this eliminates the cross product from the term, since we know that the same cross product must be present at the same position in the included term. Again, we can use the ($._{LR}$) rule to mimic the branching in $\pi$ and create a branch with $(A_1 \times A_2) \subseteq (A_1 \times A_2)$ and another with the remaining term. \\

Hence, we can use branching in $\prf_\pi$ whenever it occurs in $\pi$ and keep the semantics the same. 
\end{proof}


\subsection{Finite Proofs}\label{sec:finiteproofs}

For proving completeness, we will first translate all finite proofs of Grünke et al. into relational inclusion proofs. Finite proofs are those which do not use the Kleene-star rules ($*L$),($*R$),($\neg *L$) and ($\neg *R$) infinitely often. \\
Looking at the rules of Grünke et al., we can observe that any positive literal in RISF will be decomposed by applying rules to the $e_1.\relr$ term. The goal of the decomposition is to get an event $f_1$ for which $(e_1,f_1) \in \relr$ holds. If that point is reached, the ($eL$) rule can be applied, yielding $f=e_2 \land f_1 \neq \emptyset$. \\
The positive rules in \cite{Gru+26} only ever introduce atomic predicates like $e_1 = e_2$ or $(e_1,e_2) \in \relr$. The decomposition therefore only takes place on one predicate which is never split.

For the negative literals in RISF the decomposition starts with $e_1.\rels$. At the end, the procedure gives us an event $f_1$ from positive reasoning, yielding $(e_1,f_1) \in \rels \land \neg (f_1 \cap e_2 \neq \emptyset)$ and after applying ($\neg \cap_e$) we get $(e,f_1) \in \rels \land \neg f_1=e_2$, which would mean that there is no $e_2$ with $(e_1,e_2) \in \rels$. \\
Putting both together, we get
\[(e_1,f_1) \in \relr \land f_1 = e_2 \land f_1 \neq \emptyset \land (e_1,f_1) \in \rels \land \neg (f_1 =e_2)\]
It is already clear that there is a contradiction of the type ($\bot_0$) demands and the cube will be closed.  
Because both formulas use the same events, this equates to

\[\exists e_1,f_1: (e_1,f_1) \in \relr \land (e_1,f_1) \notin \rels\]

which is equivalent to the definition of $\semsof{\relr~ \cap \sim \rels} \neq \0$ which in turn is equivalent to $\semsof{\relr} \nsubseteq \semsof{\rels}$. \\
We will see that any formula $\phi'$ that is a decomposition from a RISF formula is equivalent to such an inclusion.

\begin{lemma}[Decomposition Lemma]\label{lem:decomposition}
Let $l[e_1.\relt]$ be a literal in a cube. Eventually, every proof $\pi$ will either decompose the predicate to $l[f]$ or close the branch with $\bot_0$.
\end{lemma}
\begin{proof}
To prove the lemma, we will divide the rules that can be applied to the literal into two groups:\\
\paragraph{Decomposing Rules: } These rules directly transform $l[e_1.\relt]$ into $l[f]$ or close the branch. In this group are ($aL$), ($\id L$), ($\neg aL$), ($\top_2$) in connection with ($\top_1$) and ($\neg \top_1$), ($\cdot^\inv L$) in connection with ($aL$) or ($\neg aL$) and the Kleene star rules ($*L$) and ($\neg *L$). The last two are also another group, since they only yield $l[f]$ in one branch or new predicate. \\
For the (${\times}L$) rule the lemma holds, considering that the ($A$) rule will be applied to the resulting set. \\
For the ($\neg {\times}L$) rule we use the same argument with the ($\neg A$) rule. The precondition of $e \in A$ will always be met. \\
For a term $\Gamma, \neg p[e.(A \times B)]$ in the premise, the rule creates two branches $\Gamma, \neg e \cap A \neq \emptyset$ and $\Gamma, \neg p[B]$ that will both be closed.
For the former branch, it can only be closed with $f_1 \in A, \neg e = f_1$, since otherwise either the cube could have been closed before the branching or $\pi$ would not be the shortest proof.
The latter branch will always result in a term of the form $B \cap f$ if no $f_2 \in B$ is available. If the context is $B.\relt \cap e_2$, the ($\neg_{\cdot_{1,2}}R$) rule enables a decomposition of \relt{} from the right side. As no negated rule besides ($\neg \cap_e$) yields a negated atomic predicate, the branch cannot be closed without resolving $B \cap f$ where $f$ is the event resulting from the decomposition.
If the context is $B \cap (e.\relt)$, the decomposition of $e.\relt$ can, again, not close the branch and only produces an event $f$.
The term $B \cap f$ can only be resolved when $f_2 \in B$ exists and it needs to be resolved to close the branch. Due to $\pi$ being the shortest proof, the branch has to be closed with this predicate and $f_2 \in B$ exists and therefore the ($\neg A$) rule is applicable directly after the ($\neg {\times}L$) rule. \\
For ($\bot_2 L$) we consider that in positive reasoning the following rule ($\bot_1$) will close the branch and in negative reasoning, the rule would never be used. \\
The reason for this argument is, that since $\pi$ is the shortest possible proof for the inclusion, no rule will be invoked unnecessarily. The ($\bot_2$) rule yields the empty set $\bot_1$ as a distinguished predicate, which in negative reasoning means that in the including term, there is an empty relation that is unified with other relations. The only reason why this predicate might be decomposed would be when the included term is the empty relation too. In that case, the branch would have been already closed via the ($\bot_2$) and ($\bot_1$) rules in positive reasoning. \\
For ($\cdot^\inv L$) the lemma holds because we can assume according to \Cref{lem:inversion} the relation is a base relation and the resulting $\relr.e$ can be converted to $f$ via ($aR$) in positive reasoning and ($\neg aR$) in negative reasoning. Again, the precondition of $(f,e) \in \relr$ is met. \\
Towards a contradiction, we assume that the precondition $(f,e) \in \relr$ does not exist. If we look at the term as a whole, then $e.\relr^\inv$ has to be concatenated to another term on the right side, in an intersection with another term or the only term left. In all three cases ($(\relr.e).\relt$ or $(\relr.e) \cap (e.\relt)$ or $(\relr.e) \cap e_2$), there is no rule applicable now that wasn't before. Therefore either the branch must be closed or $(f,e) \in \relr$ has to exist. For the branch to be closed, the same predicate (with $\relr.e$) has to appear positively. Because the positive term can always be decomposed into atomic predicates according to \cite{Gru+26}, this is not possible and the branch cannot be closed and furthermore, $(f,e) \in \relr$ has to exist.
In summary, each rule produces only atomic predicates or replaces the $e_1.\relr$ term in the predicate with $e'.\relr'$ or $f$ if the cube cannot be closed. \\

\paragraph{Structural Rules: } The structural rules do not decompose $e_1.\relt$ but handle the relational term $\relt$ and place the event $e_1$ in the correct position for further decomposition.
In this category we have ($\cap_2L$), ($._{2,2}L$), ($\cup_2L$), ($\neg \cup_2 L$) and the remaining branch of ($*L$) and the second predicate of ($\neg *L$). \\

To show that $l[e_1.\relt]$ will always be decomposed into $l[f]$ or $\bot_0$, we perform an induction on the size of $\relt$. 
The size of the relational term is equivalent to the number of occurrences of base relations in $\relt$. 
In the base case, $\relt$ is a (inverted) base relation or a cross product of base sets and we can apply one of the decomposing rules. \\
As the induction hypothesis we assume that any term $\relt'$ of a particular length $n \in \N$ will be decomposed into an event $f_n$. \\ 
If the last remaining base relation $\relt_n$ is connected to $\relt'$ via an intersection, and the ($\cap_2 L$) rule is used at some point in the proof, then we can apply a decomposing rule to the remaining base relation yielding $f'$ and use the ($eL$) rule to get $f$ or use the ($\neg \cap_e$) rule to close the branch with contradiction. \\
If the last base relation is connected via concatenation, the term we have to resolve is $f_n.\relt_n$ which only requires either ($aL$) or ($\neg aL$) which are decomposing rules. \\
For a union, the branching reduces the term into two terms of length $n$ which according to the hypothesis will be decomposed into an event. \\
A Kleene star can be transformed into arbitrarily many concatenations and therefore the argument follows the one for ($._{2,2}L$) 
\end{proof}

For the remaining rules of Grünke et al., we will now give translations into our rules.
We will start with the positive reasoning and explain what our proof system needs to provide in order to mimic the behavior of Grünke et al.'s. 

As we have seen in \Cref{lem:decomposition} we can always assume the term to which a rule is applied to be $p[e_1.\relr]$ for positive reasoning or $\neg p[e_1.\rels]$ for negative reasoning or a term that is the result of a preceding rule. Any rule application that might follow automatically will be mentioned in the same paragraph.  

\subsubsection{Positive Reasoning} 
In positive reasoning, only the branching rules have a real effect on the translated proof $\prf_\pi$. All the others only produce atomic predicates that will be used for contradictions in negative reasoning.

\paragraph{Elimination} If $\relr$ cannot be decomposed any further (for example, if it is a CAT base relation), only the ($aL$) rule can be applied. This turns $p[e_1.\relr]$ into $(e,f) \in \relr \land p[f]$.
Since this rule only introduces a new event and does not change the structure of the term, the relational inclusion would remain unchanged.
The same goes for the subsequent application of the ($eL$) rule.  

\paragraph{Concatenation} If $\relr = \relr_1.\relr_2$, the ($._{2,2}L$) rule is applied and the result is
\[p[(e_1.\relr_1).\relr_2]\]
Here, the decomposition of Grünke et al. would continue with $e_1.\relr_1$ before it continues at some point in the future with $f.\relr_2$. \\
This rule sets the order in which the decomposition continues. It changes nothing of the structure of the term and thus there is no need to translate it. \\

%-------------------------------- r_1 \cup r_2
\paragraph{Union} If $\relr = \relr_1 \cup \relr_2$ then Grünke et al. will apply ($\cup_2L$) and branch the tableau. The result are these two terms:
\begin{mathpar}
\inferrule*[left=($\cup_2 L$)]{\Gamma, p[e_1.(\relr_1 \cup \relr_2)]}{\Gamma, p[e_1.\relr_1] \\\mid \\ \Gamma, p[e_1.\relr_2]}
\end{mathpar}
%\[p[e_1.\relr_1] \qquad \mid \qquad p[e_1.\relr_2]\]
The resulting terms preserve the form of the predecessor and the decomposition can continue in both branches. Translated into our proof system we can do the following derivation which also uses branching:
\begin{mathpar} 
\inferrule*[left=($\cup_L$)]{\relr_1 \subseteq \rels \\ \relr_2 \subseteq \rels}{\relr_1 \cup \relr_2 \subseteq \rels}
\end{mathpar}

\noindent In both systems, the reasoning continues for the two relational terms that were unified before. The correctness of this translation originates from \Cref{lem:branching}. \\
Since we need the union to be the outermost operator for the branching, we may need to use the ($._{\cup dist}$) or ($\cap_{\cup dist}$) rules. This is how we can take the context with us into the branches. \\

%------------------------------ r_1 \cap r_2
\paragraph{Intersection} If $\relr = \relr_1 \cap \relr_2$, Grünke et al. apply the ($\cap_2L$) rule resulting in 
\[p[(e_1.\relr_1) \cap (e_1.\relr_2)]\]
The decomposition continues for $e_1.\relr_1$ and $e_1.\relr_2$. At the end of either decomposition new events $f_1,f_2$ take the places of each of these terms according to \Cref{lem:decomposition} and the ($eL$) rule can be applied, resulting in one of these events being passed on to the surrounding term and producing $f_1 = f_2$.
Again, this term does not change the structure of the term and needs no translation.\\

\paragraph{Kleene-star}
In the case that $\relr = \relr_1^*$, Grünke et al.'s proof would use the ($*L$) rule which branches the tableau into one branch pursuing a counterexample where $r=\id$ and one branch where $r = r^+$.
By using the ($*$) transformation, making the union the outermost operator and using the ($\cup_L$) rule we can branch with the same effect in $\prf_\pi$:
\begin{mathpar}
\inferrule*[left=($*$)]{
	\inferrule*[Left=($\cap_{\cup dist}$)($._{\cup distL}$)($._{\cup distR}$)]{
		\inferrule*[Left=($\cap_{\cup dist}$)($._{\cup distL}$)($._{\cup distR}$)]{					\inferrule*[Left=($\cup_L$)]{\Delta[\relr^+] \subseteq \rels 
			\\ 
			\Delta[\id] \subseteq \rels}{\Delta[\relr^+] \cup \Delta[\id]}		
		}{\dots}	
	}{\Delta[\relr^+ \cup \id] \subseteq \rels}
}{\Delta[\relr^*] \subseteq \rels}
\end{mathpar}
The outermost operator means that the whole term $\relr$ is of the form $\relr_1 \cup \relr_2$. For any union, we can always make it the outermost operator by applying the ($\cap_{\cup dist}$), ($._{\cup distL}$) and ($._{\cup distR}$) rules which distribute other binary operators into a union.

%------------------------------- e x A
\paragraph{Cross Product} If $\relr = (A_1 \times A_2)$ with $A_1,A_2 \subseteq E$, Grünke et al. would apply the (${\times} L$) rule preceded by the ($A$) rule which produces $f_1 \in A_1, e_1 = f_1, f_2 \in A, p[f_2]$, again passing a new event onto the surrounding term. Once more, this would not change the relational term and therefore no action is needed in our system. However, if one of the sets is a union of multiple sets the situation is different: \\

%In the case that $\relr= (B \times A)$, the ($A$) rule can be applied, yielding the demanded form of $(e_3 \times A)$. In the case that $\relr = (A \times e_3)$, $\pi$ would again first use the ($A$) rule and then continue as described above.
%Since in rational CAT the use of union is restricted to relations, there cannot be a set $A_1 = A_1' \cup A_1''$ and the rule ($\cup_1$) will never be applied in $\pi$.
\paragraph{Set union} If $A_1 = A_1' \cup A_1''$, then the ($\cup_1$) rule would branch the tableau before applying the ($A$) rule.
To do this in our proof system, we need to transform $(A_1' \cup A_1'') \times A_2$ into $(A_1' \times A_2) \cup (A_1'' \times A_2)$ via ($\times_{\cup distR}$) or ($\times_{\cup distL}$), if the union concerns $A_2$. After that we can simply use the procedure for translating the ($\cup_2L$) rule to split our tableau. \\

%------------------------------- id
\paragraph{Identity} If $\relr = \id$, the ($\id L$) rule will transform $e_1.\id$ into $e_1$. This eliminates \id{} from the formula. The consequences of this rule depend very much on the context. If the context is $\relr'.\id.\relr''$, the rule truly eliminates \id{} since it has no effect on the term. Equivalently, we can use the ($\id_{conc}$) rule in our proof system.
If the context is $\relr' \cap \id$, the rule preserves \id{} by decomposing it not into a new event but into $e_1$. In this case, we do not apply a rule in our system.
If the context is $e_1.(\id \cup \relr')$, the ($\cup_2L$) rule in $\pi$ would have been applied before and in our system the ($\cup_L$) rule. \\

%------------------------------- \bot2
\paragraph{Empty Relation} If $\relr = \bot_2$ ($= \0$) and the ($\bot_2L$) rule is applied, the result is $\bot_1$ which is the empty set $\emptyset$. As any positive predicate that includes $\bot_1$ will be turned into $\bot_0$ via the ($\bot_1$) rule, this would close the branch. 
We would write \0{} instead of $\bot_2$ and use the ($\0_\cap$) and ($\0_{conc}$) rules depending on the context. \\
Because we can assume that any union would have been branched before, ($\0_\cup$) is not needed. Instead we would have a branch where the included term consists only of \0{} and we can apply the (\textsc{empty}) rule to close the branch. \\
For intersection and concatenation our rules result in the elimination of the context, leaving only \0. Again, we can use the (\textsc{empty}) rule and close the branch. \\

%------------------------------ \top2
\paragraph{Full Relation} If $\relr = \top_2$ ($= (E \times E)$) and Grünke et al. apply the ($\top_2L$) rule, the term $e_1.\top_2$ is replaced by $\top_1$ which is the full set of events $E$. In positive reasoning, Grünke et al. would apply the ($\top_1$) rule next and with that create a fresh event $f$ that is not constricted to being part of any relation.
In our system, we need to be more aware of the context. For an intersection $(E\times E) \cap \relr'$ this equates to the ($\textsc{full}_\cap$) rule, which eliminates the full relation.
For a concatenation, the full relation would stay and we would not apply any rule.

\paragraph{Inversion} If $\relr = \relr'^{-1}$ then we can assume that $\relr'$ cannot be decomposed any further according to \cref{lem:inversion}. Therefore, after applying the ($\cdot^{-1}L$) rule, the ($aR$) rule can be used, yielding a fresh event $f$ as demanded by the decomposition lemma.
Since the inversion is still in the term as an inverted edge $(f,e)$, we do not need to apply any rule in the corresponding relational inclusion proof.

\subsubsection{Negative Reasoning}\label{sec:negreasoning}
For \rels{} the rules that Grünke et al. apply are mostly different. First, the ($._{2,2}$), ($\neg {\cup_2}L$), ($\neg * L$) and ($\cap_2L$) rules create a number of disjunct terms which only use concatenations and intersections. After that, the atomic predicates from positive reasoning are used to eliminate those relations that are in \relr{} too by using the ($\neg aL$), ($\neg{\times}L$), ($\id L$), ($\top_2L$), ($\bot_2L$) and ($\neg eL$) rules. 

\paragraph{Concatenation} If $\rels = \rels_1.\rels_2$, Grünke et al. would again apply the ($._{2,2}L$) rule resulting in $\neg (e_1.\rels_1).\rels_2$. According to the decomposition lemma, at some point in the future $e_1.\rels_1$ will have been decomposed into an event $f_1$ and the decomposition continues with $f_1.\rels_2$. \\

The concatenation has a special case. When we have a term $\neg e_1.\rels_1.\rels_2 \cap e_2 \neq \emptyset$, the ($\neg ._{1,2}$) rule becomes applicable yielding as a conclusion $\neg e_1.\rels_1 \cap \rels_2.e_2 \neq \emptyset$. As there are no similar rules for positive reasoning, according to \Cref{lem:decomposition} $\pi$ yields an event $f$ with $(e_1,f) \in \relr$ and $f = e_2$.
In a decomposition without ($\neg ._{1,2}R$), the proof will yield the predicate $\neg f = e_2$ directly constructing a contradiction.
If the ($\neg ._{1,2}R$) rule is applied and we get a subterm $\rels_2.e_2$, there will not exist an event $f'$ with $(f',e_2) \in \rels_2$ from positive reasoning. But there will be a predicate $(f',f) \in \rels_2$. At this point $\pi$ has to apply the ($\neg {\equiv} L$) rule to create a contradiction. Thus, the application of ($\neg ._{1,2}$) will take longer than not applying it and therefore this proof cannot be the shortest one. 

\paragraph{Union} If $\rels = \rels_1 \cup \rels_2$, the ($\neg {\cup_2} L$) rule would be applied, resulting in $\neg p[e_1.\rels_1] \land \neg p[e_1.\rels_2]$. The form required by the decomposition lemma remains. The intuition for the conjunction is that any counterexample must not be in $\rels_1$ and $\rels_2$. Translated into the relational inclusion this corresponds to $\relr$ being a subrelation to $\rels_1$ or $\rels_2$. As we argued in \Cref{lem:branching}, the splitting of the predicates coincides with a union of the according relational terms. We could therefore use the ($\cap_{\cup dist}$) and ($._{\cup dist}$) rules to make the union the outermost operator and continue the decomposition inside the individual terms of the union.

\paragraph{Intersection} If $\rels=(\rels_1 \cap{} \rels_2 \cap{} \dots).\rels'$ and thus we have $e_1.(\rels_1 \cap{} \rels_2 \cap{} \dots).\rels'$, the ($\cap_2L$) rule can be applied. It creates the term $(e_1.\rels_1) \cap (e_1.\rels_2) \cap \dots$ where the decomposition can continue for all parts of the intersection, since the required form is retained.
Because the rule can be applied to each intersection consecutively, it is sufficient to inspect only one. 
For the relational inclusion we do not need to apply any rule for the same reason as in the positive reasoning. \\
At some point in the future, the decomposition of both terms will be finished and returns events $f_1,f_2$ for a term $\neg p[f_1 \cap f_2]$.
In that case, $\pi$ would apply the ($\neg eL$) rule, branching the tableau and essentially eliminating the intersection from the term. The condition for this rule is that an included intersection appears at the same position in the term in \relr{}. \\
This can be seen in the fact that $f_1,f_2$ need to originate in positive reasoning and because one branch uses the predicate $\neg (f_1 \cap f_2 = \emptyset)$ which has to result in $\neg f_1 = f_2$.
Since no further decomposition is possible and there was no contradiction before, this predicate has to produce it. Hence, there must be a predicate $f_1 = f_2$ in positive reasoning, meaning that the intersection is part of the included term. \\
The only exception for this is when one relation in the intersection is the full relation $\top_2$. In this case $\pi$ would have applied the ($\top_2L$) and ($\neg \top_1$) rules where an event would have been chosen accordingly. \\
In $\prf_\pi$ we apply at this point the ($._{LR}$) rule, branching the tableau too and using one branch to show $\relr_1 \subseteq \rels_1 \cap \rels_2$. \Cref{lem:branching} justifies this. \\
\begin{mathpar} \inferrule*[left=($._{LR}$)]{\relr_1 \subseteq \rels_1 \cap \rels_2 \\ \relr' \subseteq \rels'}{\relr_1.\relr' \subseteq (\rels_1 \cap \rels_2).\rels'}
\end{mathpar}
The key difference between $\pi$ and $\prf_\pi$ is that $\pi$ will decompose the intersection before it branches it off and only shows that the whole term includes whatever is in the included term at that position afterwards. $\prf_\pi$ simply branches off the intersection and the term in $\relr$ and then shows the inclusion between the two. \\
For the case with $\top_2$ we refer to the according paragraph.
This branch can then be closed using the (\textsc{reflexivity}) rule or the ($\cap_L$) rule if the included term features more intersections.  


\paragraph{Kleene-star} If $\rels = \rels_1^*$, the next rule in $\pi$ would be ($\neg *L$). This splits the predicate $\neg p[e_1.\relr^*]$ into two new predicates $\neg p[e_1], \neg p[(e_1.\relr).\relr^*]$, letting the decomposition continue as demanded in \Cref{lem:decomposition}. In $\prf_\pi$ the corresponding action would be to use the ($*$) transformation on $\relr^*$ and then make the new union the outermost operator. According to \Cref{lem:splitting} this is equivalent to the new predicates in $\pi$.

\paragraph{Identity} If $\rels=\id$, the next rule in $\pi$ is ($\id L$) which eliminates the \id{} relation, leaving only the event $e_1$ behind.
In $\prf_\pi$, this is the same case as in the positive reasoning. Accordingly we can use ($\id_{conc}$) or no rule at all depending on the context.

\paragraph{Empty Relation} If $\rels=\bot_2$, Grünke et al. would apply ($\bot_2 L$) as in positive reasoning. In a shortest proof $\pi$ however, the rule is never used. As the inclusion must be true and there is an empty relation in the including term, either the empty relation is not needed to prove the inclusion (implying that the rule will not be used) or the empty relation is also the included term. In that case, the positive reasoning would have closed the branch already with the ($\bot_0$) rule (see paragraph on the empty relation in positive reasoning).
Hence, this rule would never be used in $\pi$


\paragraph{Full Relation} If $\rels= \top_2$, ($\top_2L$) can be invoked. This yields $\top_1$ to which Grünke et al. apply the ($\neg\top_1$) rule. This produces $\neg p[e]$ where $e$ is an event which appears positively in $\Gamma$, meaning it is an event that appears in the positive reasoning. Depending on the context, the decomposition can now continue. In the case that there is no context, choosing $e_2$ for the event will construct a contradiction. The ($\neg \cap_e$) rule derives $\neg e_2 = e_2$ and from that ($\neg =$) infers $\bot_0$ and closes the branch. 
In our system this equates to using the (\textsc{full}) rule, which closes the branch if the including term is the full relation.
For other contexts, Grünke et al. choose other events. The behavior meanwhile is consistent with how our rules work. For the context of an intersection, the full relation can be eliminated. For this case we use the ($\textsc{full}_\cap$) rule. In the context of a concatenation, we leave the full relation untouched and don't apply any rule.

\paragraph{Inversion} If $\rels = \rels'^{-1}$, we can assume according to \cref{lem:inversion} that $\rels'$ cannot be decomposed any further. Therefore $\pi$ uses ($\cdot^{-1}L$) before applying ($\neg aL$) and deriving $\neg p[\rels'.e_1], (f,e_1) \in \rels', \neg p[f]$ where the decomposition yields an event from positive reasoning $f$ as required by \cref{lem:decomposition}.
Contrary to positive reasoning, here the inversion is eliminated from the term with the application of the ($\neg aR$) rule. Since ($\cdot^\inv L$) would only be invoked in the shortest proof if the relation can be eliminated, $\rels^\inv$ must appear at the same position in the included term.
Hence, in our system we will apply a variation of the ($._{LR}$) rule called ($._{elim}$):
\begin{mathpar}
\inferrule*[left=($._{elim}$),vcenter]{\rels \subseteq \rels'}{\relr.\rels \subseteq \relr.\rels'} \quad = \quad \inferrule*[right=($._{LR}$),vcenter]{
	\inferrule*[Left=(refl.)]{\true}{\relr \subseteq \relr} 
	\\
	\rels \subseteq \rels'
}{\relr.\rels \subseteq \relr.\rels'}
\end{mathpar}

\paragraph{Cross Product} If the ($\neg {\times}L$) rule is used on a cross product we use the ($._{LR}$) rule as stated in the proof for \Cref{lem:branching}.
If $(A_1 \times A_2)$ was part of an intersection, we would refer to the paragraph on intersections.
If any of the sets are the empty or full sets, we refer to the corresponding paragraphs for anything happening after the branching.

\paragraph{Set union} If the ($\neg \cup_1$) rule is used in $\pi$, the predicate is split. As in rational CAT, sets are only used in cross products, this would only be applied to terms where one set of the cross product is a union like for example $p[(A_1 \cup A_2) \times A_3]$. Like in positive reasoning, for $\prf_\pi$ we can use the transformations ($\times_{\cup distL}$) and ($\times_{\cup distR}$) to distribute the cross product into $p[(A_1 \times A_3) \cup (A_1 \times A_3)]$. From \Cref{lem:splitting}, we know that this union, when we make it the outermost operator, is equal to splitting the predicates and we can continue with the procedure as stated in the paragraph on regular unions.

\paragraph{Elimination ($\neg aL$):} If \rels{} in $e_1.\rels$ is simply a base relation, Grünke et al. would want to apply ($\neg aL$). This is only possible if the positive reasoning provides an atomic predicate $(e_1,f_1) \in \rels$ as a premise. This corresponds to the existence of a term $\rels$ or $\rels \cap \rels'$ at the same position in the included term. The ($\neg aL$) rule produces $\neg p[e_1.\rels] \land (e_1,f_1) \in \rels \land \neg p[f_1]$. Since this essentially eliminates a concatenated relation at the start of the term we need to apply a rule in $\prf_\pi$ that does the same. For this purpose, we use again the ($._{LR}$) rule.\\
While this rule opens a new branch in $\prf_\pi$, it can be closed immediately by applying either the (\textsc{reflexivity}) rule or the ($\cap_L$) rule.

\paragraph{Event intersection ($\neg \cap_e$):} The ($\neg \cap_e$) will be applied in $\pi$ if all relations were decomposed and only $f_n \cap e_2 \neq \emptyset$ is left. After applying the rule, $\neg f_n = e_2$ is all that remains from the predicate and if there exists $f_n = e_2$ from positive reasoning, $\pi$ would apply ($\bot_0$) rule, closing the cube and branch. Since the rule is only applied if it changes the cube towards a contradiction, the predicate from positive reasoning has to exist.
In $\prf_\pi$, when all relations were decomposed and eliminated, this results in an inclusion $\0 \subseteq \0$ where the (\textsc{reflexivity}) rule gives us \true. 

\paragraph{($\neg {\equiv} L$):} This rule is used in $\pi$ whenever a property is true for multiple events but only one of them was used for further decomposition. The only case where this is important is for an inclusion of the type $\relr \cap \rels \subseteq \rels$. Here, $\pi$ would yield the events $f_1,f_2$ for $(e_1,f_1) \in \Relr, (e_1,f_2) \in \rels, f_1 = f_2$ in positive reasoning and then use $f_1$ for the intersection with $e_2$, yielding $f_1 = e_2$. Going through the steps of decomposing $\rels$, the negative reasoning only gives us $\neg ((e_1.\rels \cap e_2) \neq \emptyset), \neg f_2 = e_2$ which has no contradiction to the other predicates. Only ($\neg \equiv L$) can produce $\neg f_1 = e_2$.
Since in $\prf_\pi$ we can use the commutativity rules and ($\cap_L$), we can prevent this from happening.

\paragraph{Closing the Branch:}
The rules in \cite{Gru+26} that close a branch with $\bot_0$ are the \textit{Predicate Rules} and the set rule $(\bot_1)$. We have seen in the preceding paragraphs how these rules might be applied and what their counterparts in our proof system are. \\
The ($\neg \emptyset$) does not occur, since the decomposition of a term in RISF never yields the premise $\neg e \neq \emptyset$. \\
For the other rules we can state that ($\bot_0$) corresponds to (\textsc{reflexivity}) or ($\cap_L$) depending on the context, ($\bot_1$) corresponds to (\textsc{empty}) and ($\neg =$) corresponds to (\textsc{full}). \\
If we had chosen to use the alternative definition of ($\cap_L$) in \Cref{sec:implications}, only the (\textsc{reflexivity}) rule would be the translation of ($\bot_\0$).

\paragraph{Hypotheses:}
In $\pi$ a hypothesis of the form $\relr \subseteq \relr'$ is used automatically whenever a counterexample occurs that can be disproved by it. The hypothesis then takes on the form of a negated rule:
\begin{mathpar} \inferrule*[left=($\relr \leq \relr'$)]{\Gamma, \neg p[e.\relr']}{\Gamma, \neg p[e.\relr'], \neg p[e.\relr]}
\end{mathpar} 
As we know from \Cref{lem:splitting}, the splitting of the predicate in negative reasoning is equivalent to creating a union. Here, the union consists of the relational term that was given and the same term with $\relr'$ being replaced by $\relr$. \\
Although we do not have a rule to create arbitrary unions, we can produce the same term in $\prf_\pi$ anyways with the help of the (\textsc{strength}) rule:
\begin{mathpar}
\inferrule*[left=(strength)]{
	\rels \subseteq \Delta[\relr'] \cup \Delta[\relr]
	\\
	\inferrule*[Right=(weak)]{
		\inferrule*[Left=(assume)]{true}{\relr \subseteq \relr'}
		\\
		\inferrule*[Right=($\cup_L$)]{
			\inferrule*[Right=(reflexivity)]{true}{\Delta[\relr'] \subseteq \Delta[\relr']}
		}{\Delta[\relr'] \cup \Delta[\relr'] \subseteq \Delta[\relr']}
	}{\Delta[\relr'] \cup \Delta[\relr] \subseteq \Delta[\relr']}
}{\rels \subseteq \Delta[\relr']}
\end{mathpar}
The hypotheses in \cite{Gru+26} correspond to the relation-specific rules in \Cref{sec:relationspecific} and the assumptions and definitions in \Cref{sec:assumptions}. One can see in the preceding tableau, how we can integrate these to mimic the behavior of $\pi$. For the definitions we can simply use the according transformation instead of the (\textsc{weak}) rule.
The extra rule in \cite{Gru+26} for the case $\relr \subseteq \id$ produces $\neg p[e.\relr'], \neg p[(e.\relr).\relr']$ which is equivalent to adding duplicated terms where $\relr$ is placed in front of any other relation where it seems necessary for the inclusion. The procedure in $\prf_\pi$ allows for this behavior since \id{} can be inserted at these positions via the inverted ($\id_{conc}$) transformation. After that, the procedure is the same. \\

In summary, we have shown that we can translate any finite RAT-CAT proof $\pi$ for a relational inclusion $\relr \subseteq \Rels$ into a relational inclusion proof $\prf_\pi$.

\subsection{Infinite Proofs}

For translating infinite proofs, the central point is to replace the cyclicity of Grünke et al. \cite{Gru+26} with a finite branch. For this purpose, we construct an invariant $\mathcal{I}$ which we can use in the $(+_L)$ rule that works for every occurrence of a backlink in the infinite branch $\pi_\infty$.
Grünke et al. explain that only the Kleene-star rules do not decompose expressions and hence, there must be infinitely many applications of those rules in any infinite branch.
Furthermore, any infinite branch has to fulfill a progress condition, which is that there must be infinitely many applications of the \textit{progressing} rules ($*L$) and ($*R$). \\
Grünke et al. then transform the infinite branches of their proofs into cyclic ones by introducing backlinks anytime a term appears a second time. The equivalence is defined to being the same term up to renaming of events and unused literals. \\
To be able to transform the infinite branches into cyclic ones, Grünke et al. introduce three new rules whose effect we will emulate with our rules again:
\begin{figure}[h]
\begin{rules}{Structural Rules}
\inferrule*[left=(SUBST)]{\Gamma}{\sigma(\Gamma)} \and
\inferrule*[left=(W)]{\Gamma, l}{\Gamma} \and
\inferrule*[left=(CUT)]{\Gamma}{\Gamma, l \\ \mid \\ \Gamma, \neg l}
\end{rules}
\caption{The structural rules of Grünke et al. (\cite{Gru+26}) needed to turn an infinite branch into a cyclic one.}\label{fig:structuralrules}
\end{figure}

The (\textsc{SUBST}) rule applies a renaming $\sigma$ to the events in $\Gamma$ in order to detect isomorphic proof nodes that only differ in the names of the events. As we do not use events in our proof system, there is no need to translate this rule. \\
The (\textsc{W}) rule is a weakening that forgets a literal. Depending on the side of the inclusion, we can use the (\textsc{strength}) rule and (\textsc{weak}) rule for the same purpose. \\
The (\textsc{CUT}) rule introduces a case distinction and branches the tableau. Translating the terms into relational inclusions according to \Cref{lem:splitting} we get a rule like this:
\begin{mathpar} \inferrule*[]{\relr \cap \relt \subseteq \rels \\ \relr \subseteq \rels \cup \relt}{\relr \subseteq \rels} \end{mathpar}
We can construct this rule with (\textsc{weak}) and (\textsc{strength}):
\begin{mathpar}  
\inferrule*[left=(weak)]{
	\inferrule*[Left=($\cup_L$)]{
		\inferrule*[Left=(strength)]{
			\inferrule*[]{}{\Relr \subseteq \rels \cup \relt}
			\\
			\inferrule*[Right=($\cup_R$)]{
				\inferrule*[Right=(refl.)]{true}{\rels \subseteq \rels}			
			}{\rels \subseteq \rels \cup \relt}
		}{\relr \subseteq \rels}
		\\
		\inferrule*[right=(weak)]{
			\inferrule*[]{}{\Relr \cap \relt \subseteq \rels}
			\\
			\inferrule*[Right=($\cap_L$)]{true			
			}{\Relr \cap \relt \subseteq \relr}
		}{\Relr \subseteq \rels}	
	}{\relr \cup \relr \subseteq \rels}
	\\
	\inferrule*[Right=($\cup_L$)]{
		\inferrule*[Right=(refl.)]{true}{\relr \subseteq \relr}
	}{\Relr \cup \Relr \subseteq \Relr}
}{\Relr \subseteq \Rels}
\end{mathpar}
Now, we can translate any step that Grünke et al. might take in $\pi_\infty$. \\
As there might exist multiple terms $\rels_i$ that induce a backlink, we need an invariant that holds for everyone of these terms.
We give an example of an infinite branch in \Cref{fig:infleft} where the $\pi$ was already translated into a relational inclusion proof with the procedure in the previous section.

\begin{mathpar}
\inferrule*[left=($*L$)]{
	\inferrule*[]{\dots}{\id \subseteq \rels_1}
	\\
	\inferrule*[]{
		\inferrule*[]{
			\inferrule*[Left=($*L$)]{
				\inferrule*[]{\dots}{\id \subseteq \rels_2}
				\\
				\inferrule*[]{
					\inferrule*[]{
						\inferrule*[left=($*L$)]{
						\inferrule*[]{\dots}{\id \subseteq \rels_1}
						\\
							\inferrule*[]{
								\inferrule*[]{\dots}{\relr^* \subseteq \textcolor{blue}{\rels_2 \qquad \circ}}
							}{\dots}
						}{\relr^* \subseteq \textcolor{red}{\rels_1 \qquad \bullet}}
					}{\dots}				
				}{\relr^+ \subseteq \rels_2}			
			}{\relr^* \subseteq \textcolor{blue}{\rels_2 \qquad \circ}}
		}{\dots}	
	}{\relr^+ \subseteq \rels_1}
}{\relr^* \subseteq \textcolor{red}{\rels_1 \qquad \bullet}}
\end{mathpar}
\caption{An example of an infinite branch $\pi_\infty$ in a RAT-CAT proof $\pi$ that has been translated into a branch $\B_\infty$ of a relational inclusion proof $\prf_\pi$. To make the structure clearer, the labels are still the rules of Grünke et al. \cite{Gru+26}. The backlinks are marked with \textcolor{red}{$\bullet$} and \textcolor{blue}{$\circ$}} \label{fig:infleft}
\end{figure}
To transform the backlinks in $\pi$ into an invariant for $\prf_\pi$ we use a procedure that is inspired by the one by Das, Doumane and Pous \cite{Das+18}. In their work, they prove completeness of left-handed Kleene Algebra by transforming cyclic proofs of HKA \cite{DasPou17} into $\ell$KA proofs using invariants.
They mention that if intersections were allowed in Kleene Algebra, they would choose the intersection of the including terms of any occurrence of a backlink as the invariant. Since rational CAT allows for intersections, we can use those as invariants.

We let $\pi$ be a RAT-CAT proof and $\pi_\infty$ the branch that applies a progressing Kleene-star rule (($*L$),($*R$)) infinitely often and is therefore cyclic. 
In $\prf_\pi$ we would replace the infinite branch $\B_\infty$ with the rule ($+_L$) where we use an invariant $\I$ that is an intermediate term between \Relr{} and \Rels{} and a fixed point for $\relr^+$.
As mentioned, we choose the intersection of the including terms as the invariant:
Let $s_i, i \in [1,n]$ be the terms that are supposed to include $\relr^+$
\[\I = \bigcap_{i=1}^n \rels_i\]
The invariant $\I$ has to fulfill three properties according to our invariant rule:
\[
\textbf{(P1)}~ \relr \subseteq \I \qquad
\textbf{(P2)}~ \relr.\I \subseteq \I \qquad
\textbf{(P3)}~ \forall i \in [1,n]: \I \subseteq \rels_i 
\]
We know that $\pi$ is a closed proof and $\relr^+ \subseteq \rels_i$ holds for all $i \in [1,n]$. Furthermore, we can assume that every $s_i$ can be transformed into $\relr.\rels_i$, since between the occurrences of the term a $\relr$ term that is concatenated on the left side (since we can assume only ($*L$) is used according to \Cref{lem:decomposition}) can be split off. Using this information we can prove the properties:

\paragraph{(P1)} $\relr \subseteq \bigcap_{i = 1}^n \rels_i $
\begin{proof}As we have just mentioned, we know that $\relr \subseteq \rels_i$ holds for every $\rels_i$. The conjunction of these facts is exactly the definition of the intersection of all the $\rels_i$ terms. \end{proof}

\paragraph{(P2)} $\relr.\left( \bigcap_{i = 1}^n \rels_i \right) \subseteq \bigcap_{i = 1}^n \rels_i$
\begin{proof}
From $\pi$ being a closed tableau we know that $\relr^+ \subseteq \rels_i$ holds for every $i \in [1,n]$ and since we will receive $\relr^* \subseteq \rels_i$ from $\relr^+ \subseteq \rels_i$, we know that any $s_i$ can be resolved to $\relr.\rels_i$. Applying this to the invariant, we can deduce that it can be transformed to $\bigcap_{i = 1}^n \relr.\rels_i$.
\begin{eqnarray*}
\edgein \relr.(\bigcap_{i = 1}^n \rels_i) &\impl & \exists e_1: (e,e_1) \in \relr \land (e_1,e') \in \bigcap_{i = 1}^n \rels_i \\
& \impl & \exists e_1: (e,e_1)\in \relr \land \bigwedge_{i=1}^n (e_1,e') \in s_i \\
&\impl & \exists e_1: \bigwedge_{i=1}^n (e,e_1) \in \relr \land (e_1,e') \in \rels_i \\
&\impl & \edgein \bigcap_{i = 1}^n \relr.\rels_i = \bigcap_{i = 1}^n \rels_i
\end{eqnarray*}
\end{proof}

\paragraph{(P3)} $\bigcap_{i = 1}^n \rels_i \subseteq \rels_i$ for every $\rels_i$
\begin{proof}
As we can reformulate the term for every $\rels_j$ as $\rels_j \cap (\bigcap_{i=1}^n \rels_i) \subseteq \rels_j$ and we know from the soundness proof of ($\cap_L$) that $\relr \cap \relr' \subseteq \relr$ holds, \textbf{(P3)} holds for the invariant.
\end{proof}

\begin{lemma}\label{lem:properties} The proof tableaus for the properties \textbf{\upshape (P1)}, \textbf{\upshape (P2)} and \textbf{\upshape (P3)} are finite. \end{lemma}
\begin{proof}
For \textbf{(P1)} $\relr \subseteq \I$ the proof is to apply the rules in the cyclic part of $\pi_\infty$. Since that part splits off one $\relr$ from the including terms resulting in $\relr^* \subseteq \Rels_i$ for any of the $s_i$, is must be possible to split the $\relr$ off here to produce $\0 \subseteq \rels_i$ which can then be closed by (\textsc{empty}). 
As the section of the branch between the occurrences of the term is finite, the proof for \textbf{(P1)} must be finite as well. \\
For \textbf{(P2)} $\relr.\I \subseteq \I$ a similar argument can be made. We know from the cyclic proof that it is possible to split off arbitrarily many $\relr$ from the $\rels_i$ terms and still retain the term itself. We use this in the proof of the property. Accordingly, the proof for this can be the finite section between the occurrences of the term, which produces $\I \subseteq \I$ and that can be resolved to \true{} with the (\textsc{reflexivity}) rule. \\
For \textbf{(P3)} $\forall i \in [1,n]: \I \subseteq \rels_i$ the proofs can be two rules long. First, we apply the ($\cap_{comm}$) rule to put the current term $\rels_j$ at the first position and then we invoke ($\cap_L$) to close the branch. This is a finite proof and thus, the application of the induction rule ($+_L$) yields a finite proof.
\end{proof}

\begin{theorem}[Infinite Translation Theorem]
We can translate any infinite RAT-CAT proof $\pi$ into a finite relational inclusion proof $\prf_\pi$.
\end{theorem}
\begin{proof}
We translate the proof up to the first occurrence of the ($*L$) or ($*R$) rule into a relational inclusion tableau as we showed in \Cref{sec:finiteproofs}. For the next step, we apply the ($*$) rule to split the tableau with ($\cup_{L2}$) and translate the branch concerning $\id \subseteq \rels_1$ as usual. The branch that handles $\relr^+ \subseteq \rels_1$ continues with the invariant rule ($+_L$). As the invariant we choose $\I = \bigcap_{i = 1}^n \rels_i$ where $n$ is the number of different terms that evoke backlinks. As we have shown, if $\pi$ is a proof, then the premises of the rule \textbf{(P1)}, \textbf{(P2)} and \textbf{(P3)} are fulfilled and thus, the translation is valid. 
As we know from \Cref{lem:properties} the branches for proofs for the properties \textbf{(P2)} and \textbf{(P3)} will be finite.
\end{proof}

\section{Evaluation}\label{sec:evaluation}
In this section we evaluate the capabilities of this proof system. We can compare memory models that are defined in rational CAT, a fragment of the CAT language of which the definition is found in \Cref{fig:cat}. In this respect we offer the same possibilities as Grünke et al and therefore a bigger fragment than KATER \cite{Kok+23} by Kokologiannakis at al. and KATI \cite{Kou+24} by Koutsouridis at al.. \\
The flip side of this fact is that we were not able to expand the capabilities to non-monotonic operators (complement and difference). In order to expand the proof system to all of CAT, one would need to adjust rules to include non-monotonic operators. This would mean that every implication in \Cref{sec:implications} handles only base relations and no relational terms. Furthermore, the weakening and strengthening rules would only work on whole terms and not on subterms. \\
Our proofs, if used correctly, feature no infinite tableaus or cyclic proofs but instead use invariants which need to be found by the human using the proof system. This is a disadvantage in comparison with the other proof systems, since we cannot yet automatize our rules and implement the system in a tool.

\section{Conclusion}\label{sec:conclusion}
The task for this master's thesis was to create a new proof system for comparing Memory Consistency Models that does not resolve relations to event-level, is neither cyclic nor infinite and creates proofs that are shorter then the ones in \cite{Gru+26}. We wanted the proof system to work reasonably well, prove it's soundness and completeness and have the system to cover all of CAT. Optimally, we wanted to make the proof system work automatically. \\
In the end, we have developed a new proof system for inclusions between relations and with that inclusions between Memory Consistency Models that can be defined in rational CAT. We have shown that the system is sound by proving the implications and equivalences of every rule and that it is complete by showing that every proof of Grünke et al. can be translated into our system. \\
The proof system does not resolve the relations to event level and uses invariants instead of cyclic proofs. \\
While we have shown completeness, automation of the proof system is not possible yet, since this would require a deterministic choice of invariants and of a sufficient order in which the rules are to be applied.
One could for example apply the ($\cup_{comm}$) rule indefinitely to a term $\relr \cup \Rels$ without ever yielding a proof. Applying the rules therefore still requires knowledge about the relations and what actions can produce actual results. \\
Furthermore, we have not been able to handle recursive definitions in CAT and were not able to show any new results that would not have been possible with Grünke et al's system. One reason for the latter is, that we could not expand the system to include differences $\relr \setminus \Rels$ and complements $\sim \Relr$. \\
Armed with knowledge about how to handle the rules though, users will be able to proof inclusions in a more intuitive and straightforward fashion.
As we have seen in \Cref{sec:finiteproofs} many rules for the decomposition in \cite{Gru+26} do not require any action in our system because we use no event constants. This fact can shorten the proofs substantially as we have seen in \Cref{sec:evaluation}. \\

In the future, one could expand the proof system to all of CAT or develop a mechanism to include recursive definitions. A very practical aspect is to automate this proof system in order to be able to build a tool for comparing MCMs. To make this possible, all that is needed is a method for calculating the required invariants and clear guidelines on when to use which rule.

\section{Proof of the Inversion lemma}\label{sec:inversionproof}
\Cref{lem:inversion}:
Let $\relr$ be a relational expression that features an inversion. There is an expression $\relr'$ that only features inversions that are applied to base relations with $\semsof{\relr} = \semsof{\relr'}$. 
\begin{proof}
When it can be shown for each operation in CAT that the inversion of the whole expression can be passed on to the individual terms, any CAT expression has this property. Therefore we show the property for each operation.
\begin{description}
\item[Case $(\relr \cup \rels)^\inv$:] 
\begin{eqnarray*}
\semsof{(\relr \cup \rels)^{-1}} &= &\{(e,e') \mid (e',e) \in \relr \cup \rels\} \reason{\defof \rel^{-1}} \\
&= &\{(e,e') \mid (e',e) \in \relr \lor (e',e) \in \rels\} \reason{\defof \rel_1 \cup \rel_2} \\
&= &\{(e,e') \mid \edgein \relr^{-1} \lor \edgein \rels^\inv\} \reason{\defof \rel^\inv} \\
%= &\semsof{\relr^{-1}} \cup \semsof{\rels^{-1}} \reason{\defof \rel_1 \cup \rel_2} \\
&= &\semsof{\relr^{-1} \cup \rels^{-1}} \reason{\defof \rel_1 \cup \rel_2}
\end{eqnarray*}
\item[Case $(\relr \cap \rels)^\inv$:] 
\begin{eqnarray*}
\semsof{(\relr \cap \rels)^{-1}} &= &\{(e,e') \mid (e',e) \in \relr\cap \rels\} \reason{\defof \rel^\inv}\\
&= &\{(e,e') \mid (e',e) \in \relr \land (e',e) \in \rels\} \reason{\defof \rel_1 \cap \rel_2} \\
&= &\{(e,e') \mid \edgein \relr^\inv \land \edgein \rels^\inv\} \reason{\defof \rel^\inv}\\
&= &\semsof{\relr^{-1} \cap \rels^{-1}} \reason{\defof \rel_1 \cap \rel_2}
\end{eqnarray*}
\item[Case $(\relr.\rels)^\inv$:] 
\begin{eqnarray*}
\semsof{(\relr.\rels)^{-1}} &=& \{(e,e') \mid (e',e) \in (\relr.\rels)\} \reason{\defof \rel^\inv}\\
&=& \{(e,e') \mid \exists e'': (e',e'') \in \relr, (e'',e) \in \rels \} \reason{\defof \rel_1.\rel_2}\\
&=& \{(e,e') \mid \exists e'': (e'',e') \in \relr^{-1}, (e,e'') \in \rels^{-1}\} \reason{\defof \rel^\inv} \\
&=& \semsof{\relr^{-1}.\rels^{-1}} \reason{\defof \rel_1.\rel_2}
\end{eqnarray*}
\item[Case $(\sim \relr)^\inv$:]
\begin{eqnarray*}
\semsof{(\sim \relr)^{-1}} &=& \{(e,e') \mid (e',e) \in~ \sim \relr\} \reason{\defof \rel^\inv} \\
&=& \{(e,e') \mid (e',e) \notin \relr\} \reason{\defof \sim \rel}\\
&=& \{(e,e') \notin \relr^{-1}\} \reason{\defof \rel^\inv}\\
&=& \semsof{\sim (\relr^{-1})} \reason{\defof \sim \rel}
\end{eqnarray*}
\item[Case $(\relr^+)^\inv$:]\begin{eqnarray*}
\semsof{(\relr^+)^{-1}} &=& \{(e,e') \mid (e',e) \in \relr^+\} \reason{\defof \rel^\inv} \\
&=& \{(e,e') \mid \exists n \in \N: e=e_1 \land e'=e_n \land \forall i \in [1,n]:(e_i,e_{i+1}) \in \relr\} \reason{ \rel^+}\\
&=& \{(e,e') \mid \exists n \in \N: e'=e_1 \land e=e_n \land \forall i \in [1,n]:(e_i,e_{i+1}) \in \relr^\inv\} \reason{ \rel^\inv} \\
&=& \semsof{(\relr^{-1})^+} \reason{\defof \rel^+}
\end{eqnarray*}
\item[Case $(\relr?)^\inv$:]\begin{eqnarray*}
\semsof{(\relr?)^{-1}} &=& \{(e,e') \mid (e',e) \in \relr?\} \reason{\defof \rel^\inv} \\
&=& \{(e,e') \mid (e',e) \in \relr \cup \id \} \reason{\defof \rel ?} \\
&=& \{(e,e') \mid \edgein \relr^{-1} \cup \id^{-1}\} \reason{\defof \rel^\inv} \\
&=& \{(e,e') \mid \edgein \relr^{-1} \cup \id\} \reason{\defof \id} \\
&=& \semsof{(\relr^{-1})?} \reason{\defof \rel?}
\end{eqnarray*}
\item[Case $(\relr^*)^\inv$:]\begin{eqnarray*}
\semsof{(\relr^*)^{-1}} &=& \{(e,e') \mid (e',e) \in \id \cup \relr^+\} \reason{\defof \rel^\inv \text{ and } \defof \rel^*}\\
&=& \{(e,e') \mid (e',e) \in \id \lor (e',e) \in \relr^+\} \reason{\defof \rel_1 \cup \rel_2}\\
&=& \{(e,e') \mid \edgein \id^{-1} \lor \edgein (\relr^+)^{-1}\} \reason{\defof \rel^\inv} \\
&=& \{(e,e') \mid \edgein \id \lor \edgein (\relr^{-1})^+ \} \reason{\defof \id \text{ and Case } (\relr^+)^\inv} \\
&=& \{(e,e') \mid \edgein \id \cup (\relr^{-1})^+ \} \reason{\defof \rel_1 \cup \rel_2} \\
&=& \semsof{(\relr^{-1})^*} \reason{\defof \rel^*}
\end{eqnarray*}
\end{description}
\end{proof}
